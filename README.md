# LifeGame Design

Отдельная рабочая копия LifeGame для разработки и проверки интерфейса.

## Источник

Исходная версия: `raymondovich-cloud/LifeGame`, ветка `main`.
Исходный коммит при подготовке: `4bcf36c66918705f5e21e016bef3e36ec799acba`.
Это отдельная рабочая копия, а не автоматически синхронизируемый форк.

## Назначение

- разработка визуальной системы и пользовательских интерфейсов;
- проверка адаптивности, состояний и взаимодействий;
- работа с CSS и presentation-слоем;
- подготовка небольших проверенных изменений для последующего переноса в основной проект.

## Границы ответственности

Бизнес-правила, доменные модели, авторизация, безопасность и инфраструктурные интеграции не изменяются в рамках чисто визуальных задач без отдельного согласования. Не добавлять реальные секреты, токены, ключи и пользовательские данные.

## Рабочий процесс

1. Разработка ведётся в отдельной рабочей ветке.
2. Перед изменениями проверяются архитектура и зависимости.
3. После каждого изменения добавляется запись в `docs/changes/<дата>/`.
4. Проверяются доступные автоматические тесты и визуальная регрессия.
5. Изменения переносятся в основной LifeGame только после проверки и отдельного согласования.

## Важно

Это рабочая копия для дизайна, а не независимый продукт. Источник истины по бизнес-логике и данным — основной репозиторий LifeGame.
