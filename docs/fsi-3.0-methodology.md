# FSI 3.1 — методология

**Статус:** IMPLEMENTED
**Версия модели:** 3.1  
**Дата:** 07.10.2026

## Формула

FSI = 100 × CF^0.25 × LR^0.20 × ER^0.15 × DS^0.20 × NFP^0.10 × FT^0.10

Перед агрегированием каждый компонент ограничивается снизу значением **0.05**. Это сохраняет взвешенное геометрическое среднее как модель сбалансированной системы: критически слабый компонент резко снижает FSI, но один нулевой компонент не обнуляет весь индекс.

`LR = Liquid Assets / Mandatory Outflow`

`ER = Emergency Reserve / Mandatory Outflow`

Резерв не вычитается из ликвидных активов при расчёте LR. Он продолжает отдельно отражаться в ER.

Используется взвешенное геометрическое агрегирование. Компоненты нормализуются в 0–1.

- **CF 25%** — покрытие обязательного оттока фактическим доходом.
- **LR 20%** — месяцы обязательного оттока, покрываемые всей ликвидной позицией.
- **ER 15%** — месяцы обязательного оттока, покрываемые финансовой подушкой.
- **DS 20%** — DSR 45%, DTI 25%, кредитный риск амортизации 30%.
- **NFP 10%** — чистая финансовая позиция: активы минус долг.
- **FT 10%** — тренд дохода, долга, ликвидности и резерва по snapshots.

Для кредитных продуктов учитывается процент первого месяца. Если регулярный платёж не покрывает начисленные проценты, продукт считается non-amortizing.

## Critical Risk Gates

- доход ниже обязательного оттока → максимум 59;
- DSR > 50% → максимум 59;
- non-amortizing credit product → максимум 39;
- нулевой доход при обязательствах → максимум 19.

Гейты предотвращают маскирование критического текущего риска сильными активами или резервом.

## Архитектура

Index получает данные только через Application. Application формирует историю из Finance Memory snapshots. Domain и Memory не импортируются Index напрямую.

Все текущие финансовые источники участвуют в модели: Assets, Actual Earnings, Financial Burden, Mandatory Expenses, Financial Cushion и параметры Credit Product.

## Ограничения

Текущие записи Finance не имеют обязательной периодичности дохода/расхода. Поэтому модель предполагает единый согласованный расчётный период для текущих сумм. Полноценный monthly DSR потребует отдельной модели периодичности.

FSI 3.1 научно обоснован как composite indicator, но не эмпирически валидирован. Валидация потребует обезличенных данных и проверки прогностической способности модели.

FSI 3.1 заменяет FSI 3.0 как текущую расчётную модель. как текущую расчётную модель.
