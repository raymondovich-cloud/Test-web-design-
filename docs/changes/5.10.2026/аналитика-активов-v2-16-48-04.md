# Изменение: Assets Analytics v2

**Дата:** 05.10.2026  
**Время:** 16:48:04 MSK

## Изменено

- Добавлена историческая выборка Assets snapshots по диапазону.
- Добавлены readers первого и последнего snapshot.
- Analytics Assets вынесена в отдельный Application use case.
- Убрана зависимость Assets Analytics от Domain.
- Добавлены периоды: неделя, месяц, год, свой период, всё время.
- Для custom-периода введено ограничение Free: не более 6 календарных месяцев.
- Для All Time предусмотрена Pro access policy.
- Переиспользован существующий Pro subscription modal через shared presentation component.
- Добавлены динамика активов, структура ликвидности и состав активов.
- Assets summary переведена на Analytics Application data.
- Добавлены стили Analytics v2.

## Не изменено

- FSI 2.1 не включён в Assets Analytics.
- Другие финансовые блоки не включены в Assets Analytics.
- Domain не хранит пользовательскую историю активов.

## Важно

Текущая Memory остаётся runtime-хранилищем. Persistent storage и привязка исторических snapshots к конкретному пользователю требуют отдельного этапа Infrastructure/Memory и не считаются реализованными в этой задаче.
