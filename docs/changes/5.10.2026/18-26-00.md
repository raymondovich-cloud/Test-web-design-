# Реализация выхода из профиля

**Дата:** 05.10.2026  
**Время:** 18:26 МСК

## Изменено

- В source/presentation/profile/profile.js добавлено действие «Выйти из профиля».
- Выход вызывается через переданный presentation callback, без прямого доступа Profile к Supabase.
- В platforms/web/web.js добавлена orchestration-логика logout через application.auth.logout().
- После успешного выхода очищаются authenticationEstablished и activeUserId, а web shell переводится в неаутентифицированное состояние.
- После выхода пользователь переводится на основной маршрут Finance.
- В source/infrastructure/identity/supabase.identity.adapter.test.mjs добавлены проверки успешного logout и нормализации ошибки Supabase.

## Архитектура

Поток:

Profile UI → Web presentation callback → Auth Controller → Identity Application → Identity Port → Supabase Identity Adapter → Supabase Auth

Profile не знает о Supabase и не работает с токенами или инфраструктурой.
