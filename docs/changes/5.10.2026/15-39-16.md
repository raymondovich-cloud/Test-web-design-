## Что изменено

1. Окно взаимодействия больше не вставляется непосредственно под выбранной строкой.
2. Окно теперь открывается как отдельный центральный overlay поверх интерфейса.
3. Добавлен затемняющий и размывающий backdrop, который визуально переводит остальной интерфейс на второй план.
4. Анимация окна построена через масштабирование из центра: компактное окно плавно раскрывается одновременно во все четыре стороны.
5. Сохранён существующий набор действий: редактирование, закрепление/открепление и удаление.
6. Виброотклик запускается в момент срабатывания long press перед открытием окна.
7. Telegram HapticFeedback остаётся приоритетным механизмом; browser vibration используется как fallback. Ошибка haptic API не может прервать пользовательское взаимодействие.
8. Закрытие overlay по нажатию вне окна также анимировано.

## Архитектурные решения

- Поведение взаимодействия со строкой осталось в `presentation/finance/entry.edit.js`.
- Визуальная реализация overlay и motion осталась в Design System: `source/design/components/row-interaction-menu.css`.
- Domain, Application, Memory и Infrastructure не затронуты.
- Существующая логика редактирования, закрепления и удаления не изменялась.

## Причина

Предыдущая версия привязывала окно к потоку списка и перемещала соседние строки. Новый вариант лучше соответствует премиальному мобильному интерфейсу: пользователь получает явный фокус на действии, а основной экран временно становится вторичным.
