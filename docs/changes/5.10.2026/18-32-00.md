# Скрытие пользовательских данных при выходе

**Дата:** 05.10.2026  
**Время:** 18:32 МСК

## Изменено

- Добавлено явное очищение активной Finance Memory при logout.
- Добавлено очищение readers аналитики активов.
- Logout теперь очищает in-memory состояние до повторного публичного render.
- После выхода публичный Finance не может получить данные предыдущего пользователя из старой ссылки на Memory.

## Причина

До изменения UI переходил в public mode, но Application Finance продолжал держать ссылку на Memory последнего авторизованного пользователя. Поэтому публичный render мог повторно читать старые данные до полной перезагрузки страницы.

## Результат

После выхода данные пользователя должны исчезать сразу, без reload. При следующей авторизации Memory создаётся/гидратируется заново для нового активного пользователя.

## Проверка
