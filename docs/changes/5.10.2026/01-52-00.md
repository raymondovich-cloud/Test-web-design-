## Что изменено

- Навигация переведена из модели «активный пункт = карточка» в более спокойную tab-bar иерархию.
- У активного раздела убран залитый фон.
- Активное состояние теперь обозначается тонкой оранжевой линией сверху и белым текстом.
- Линия активного состояния имеет короткую длину и мягкое появление, чтобы не превращаться в декоративный разделитель.
- Типографика navigation label переведена на единый semantic interface level.
- Сохранены существующие маршруты, порядок модулей и логика показа Profile только для authenticated state.
- На мобильной ширине индексы 01–04 по-прежнему скрываются, оставляя компактную навигацию.

## Архитектура

- JavaScript навигации не изменялся.
- Маршрутизация и application logic не изменялись.
- Изменение ограничено Design System.
- Finance, Health, Development и Profile не затронуты.
