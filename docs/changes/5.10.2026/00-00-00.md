## Изменено

В `source/design/components/accordion.css` обновлена логика нижнего разделителя открытого подблока.

Ранее линия задавалась только для `.accordion-trigger`, поэтому визуально обрывалась перед областью кнопки подсказки.

Теперь разделитель принадлежит всему `.accordion-header`:

- линия проходит по всей ширине заголовка;
- область кнопки подсказки больше не обрывает разделитель;
- логика раскрытия аккордеона не изменена;
- логика информационной подсказки не изменена;
- JavaScript не изменялся.
