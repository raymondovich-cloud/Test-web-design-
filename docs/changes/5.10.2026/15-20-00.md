# Изменение: визуал закрепления и лимит PRO

Дата: 5.10.2026
Время: 15:20 (МСК)

## Изменено

- Все три действия окна взаимодействия со строкой приведены к единому визуальному цвету.
- Убрана разноцветная семантика действий из меню: визуальная иерархия теперь строится единым акцентным стилем.
- Для закреплённых строк добавлен визуальный индикатор в виде минималистичной булавки, ориентированной на паттерн закреплённых чатов Telegram.
- Булавка отображается только у закреплённой строки.
- В каждом финансовом блоке установлен лимит в 3 закреплённые строки.
- При попытке закрепить четвёртую строку показывается отдельное премиальное всплывающее окно:
  «Расширьте подписку до уровня pro пользователя».
- Закрепление и лимит остаются presentation-логикой; финансовый Domain не изменён.
- Добавлен отдельный Design System компонент для уведомления о лимите подписки.

## Важно

Лимит применяется отдельно к каждому из пяти редактируемых финансовых блоков. Индекс финансовой стабильности не участвует в механике закрепления.
