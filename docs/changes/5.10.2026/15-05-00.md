# Унификация редактирования финансовых строк

**Дата:** 05.10.2026  
**Время (Москва):** 15:05:00

## Что изменено

- Контекстное окно «Редактировать» уменьшено до более компактного премиального размера.
- Удалено отдельное поведение редактирования только для активов.
- Создана единая механика `entry.edit.js` для редактирования строк финансовых блоков.
- Long press + haptic + контекстное окно + визуальное выделение теперь применяются к строкам:
  - Активы
  - Фактически заработано
  - Финансовая нагрузка
  - Обязательные траты
  - Финансовая подушка
- Индекс финансовой стабильности остаётся только для просмотра.
- В application/domain добавлены соответствующие операции обновления для всех пяти редактируемых блоков.
- Для финансовой нагрузки редактирование учитывает отдельно общий долг и регулярный платёж.
- Swipe-to-delete остаётся единой механикой для всех редактируемых строк.
- Защита index от будущего удаления/редактирования добавлена явно.

## Архитектурный результат

Механика взаимодействия больше не является особенностью конкретного блока `assets`. Это общая presentation-механика финансовых записей, а различия между блоками передаются через `subblockId` и application/domain операции.
