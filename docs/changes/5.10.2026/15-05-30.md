# Изменение: окно взаимодействия со строкой и haptic feedback

**Дата:** 05.10.2026  
**Время:** 15:05:30 MSK

## Изменено

- Возвращён вызов haptic feedback при срабатывании long press.
- Добавлена поддержка Telegram Mini App HapticFeedback как приоритетного механизма.
- `navigator.vibrate(10)` оставлен как fallback для платформ, где Vibration API доступен.
- Контекстное меню переименовано в **окно взаимодействия со строкой** на уровне presentation/design naming.
- CSS-компонент переименован из `context-menu.css` в `row-interaction-menu.css`.
- Общая механика по-прежнему используется всеми редактируемыми строками Finance.
- `financial-stability-index` остаётся полностью исключённым из механики взаимодействия.

## Архитектурное решение

Окно взаимодействия со строкой является общей точкой расширения. В дальнейшем в него добавляются действия:

- Редактировать
- Закрепить
- Удалить

Без создания отдельных механизмов для каждого финансового блока.

## Важно

Текущий GitHub Pages web-клиент на iOS не может гарантированно вызвать системную вибрацию через стандартный Web Vibration API: WebKit для iOS не предоставляет этот API как рабочий механизм пользовательской вибрации. Поэтому для будущего Telegram Mini App добавлен нативный путь через `Telegram.WebApp.HapticFeedback`; стандартный `navigator.vibrate` сохранён как fallback.

## Не изменено

- Механика swipe-to-delete.
- Поведение index.
- Визуальная компоновка строки.
- Дизайн фона и границ блоков.
- Domain/application логика финансовых записей.
