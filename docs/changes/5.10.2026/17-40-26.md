# Изменение архитектуры Finance — stateless Domain и user-scoped Memory

**Дата:** 05.10.2026  
**Время (Москва):** 17:40:26

## Запрос

Продолжить утверждённую миграцию Finance после перевода Assets Domain на stateless-модель.

## Изменено

### Domain

Переведены в stateless-модель:

- `source/domain/finance/actual.earnings/actual.earnings.js` — Version 2.0
- `source/domain/finance/financial.burden/financial.burden.js` — Version 2.0
- `source/domain/finance/mandatory.expenses/mandatory.expenses.js` — Version 2.0
- `source/domain/finance/financial.cushion/financial.cushion.js` — Version 2.0

Из Domain удалены:

- глобальные массивы пользовательских записей;
- глобальные счётчики идентификаторов;
- прямое хранение состояния между вызовами.

Теперь Domain:

1. принимает входные данные;
2. валидирует и нормализует их;
3. формирует новую запись без идентификатора хранения;
4. возвращает domain result + нейтральное событие;
5. не знает Memory, UserContext, Supabase или Event Bus.

### Application

`source/application/finance/finance.js` — Version 4.0.

Application теперь:

- получает записи из user-scoped Finance Memory;
- передаёт текущую запись в Domain для update/delete;
- сохраняет результат через Memory;
- сохраняет существующую семантику Financial Burden;
- рассчитывает FSI только из данных Memory;
- не хранит пользовательские Finance-записи самостоятельно.

### Finance Memory

`source/memory/finance/finance.memory.js` — Version 2.0.

Memory теперь изолирует все пять Finance collections:

- Assets;
- Actual Earnings;
- Financial Burden;
- Mandatory Expenses;
- Financial Cushion.

Каждый экземпляр Memory принадлежит одному `userId`.

Идентификаторы создаются на границе Memory, а не в Domain.

### Memory Port

`source/application/finance/finance.memory.port.js` — Version 2.0.

Port расширен операциями всех пяти Finance collections. Application зависит от контракта, а не от конкретного хранилища.

### Tests

Добавлены тесты stateless-поведения для всех четырёх мигрированных Domain-модулей.

Расширен:

`source/memory/finance/finance.memory.test.mjs` — Version 2.0.

Проверяется изоляция пользователей для всех пяти Finance collections и сохранение identity при update.

## Проверка

Проверены свежие GitHub blob-файлы:

- во всех четырёх мигрированных Domain-модулях отсутствуют `const entries = []` и `let nextId = 1`;
- Assets Memory больше не подключается напрямую из Web;
- Web не подписывается напрямую на `finance.assets.state.changed`;
- Web использует user-scoped Finance Memory через composition root;
- version markers присутствуют.

Полный Node test suite в текущей среде не запускался: среда не имеет сетевого доступа для получения репозитория и зависимостей. Поэтому тесты считаются **добавленными, но не выполненными**.
