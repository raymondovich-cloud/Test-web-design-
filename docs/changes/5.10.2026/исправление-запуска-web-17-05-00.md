# Исправление запуска Web — 05.10.2026 17:05:00 MSK

## Причина

В `source/application/finance/finance.js` после удаления старого API остался экспорт `getAssetsTotal`, хотя функция больше не существовала.

Для ES-модуля такой именованный экспорт является фатальной ошибкой загрузки. Из-за этого цепочка статических импортов `web.js` не выполнялась, поэтому на странице оставались только статическая шапка и нижняя навигация.

## Исправлено

- Удалён несуществующий экспорт `getAssetsTotal`.
- Версия `source/application/finance/finance.js` повышена с 3.1 до 3.2.
- Analytics v2 не откатывался.
- Архитектурная граница Application → Memory сохранена.
