# Изменение интерфейса редактирования активов

**Дата:** 05.10.2026  
**Время (Москва):** 14:50:00

## Что изменено

- Контекстное окно «Редактировать» больше не позиционируется поверх списка через `position: fixed`.
- Окно теперь является частью потока списка и появляется непосредственно под удержанной строкой слева.
- Нижние строки физически освобождают место под окно вместо перекрывания.
- Перемещение строк выполнено через FLIP-подобную reflow-анимацию, поэтому нижняя часть списка плавно смещается вниз.
- При активном редактировании выбранная строка сохраняет максимальный визуальный акцент.
- Остальные строки списка слегка уменьшаются по масштабу, яркости и насыщенности.
- После закрытия окна список плавно возвращается в исходное состояние.
- Сохранено разделение механики и Design System: геометрия/визуальное состояние находятся в CSS, а JavaScript только управляет состояниями и DOM-потоком.

## Изменённые файлы

- `source/presentation/finance/assets.edit.js` — Version 1.3
- `source/design/components/context-menu.css` — Version 1.3
- `source/design/components/list.css` — Version 2.4

## Результат

Окно редактирования больше не перекрывает сумму, кнопки или соседние строки. Визуальная иерархия теперь строится так:

**выбранная строка → окно редактирования → остальные строки приглушены.**
