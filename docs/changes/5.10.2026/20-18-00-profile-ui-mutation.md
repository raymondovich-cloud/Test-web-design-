# Profile UI mutation integration

Дата: 05.10.2026
Время: 20:18 MSK

## Изменено

- Подключено редактирование display name и birth date в Profile Presentation.
- Клик или Enter/Space по строке имени или даты открывает единый inline editor.
- Поля используют Design System `input-control` и не создают отдельную техническую форму вне Presentation.
- Сохранение вызывает только `profileApplication.updateProfile(userId, input)`.
- После успешной мутации UI обновляется данными, возвращёнными Application boundary.
- При ошибке сохранения форма остаётся открытой и показывает сообщение об ошибке.
- Добавлен отдельный `source/design/components/profile.css`.
- Новый CSS подключён через единый `source/design/design.css`.
- Email остаётся только для чтения.
- Logout не затронут.

## Архитектурная цепочка

`Profile UI → Profile Application → Profile Port → Supabase Profile Adapter → public.profiles`.

Presentation не получает доступа к Supabase и не знает о структуре таблицы.

## Поведение

1. Пользователь открывает Profile.
2. Имя и дата рождения отображаются как обычные строки.
3. Нажатие на любую из двух строк открывает редактор.
4. Пользователь изменяет имя и/или дату.
5. Нажатие «Сохранить» вызывает существующий mutation boundary.
6. После успешного ответа UI получает canonical данные и перерисовывает строки.

## Проверка

Проверена связка Presentation → существующий `profileApplication.updateProfile`.

Автоматический запуск браузерного сценария из текущей среды недоступен, поэтому визуальная проверка на GitHub Pages ещё требуется после загрузки новой версии.

## Статус
