# Изменение: окно взаимодействия со строкой

Дата: 5.10.2026
Время: 15:08 (МСК)

## Изменено

- Расширено общее окно взаимодействия со строкой для всех редактируемых финансовых блоков.
- Добавлены действия:
  - «Редактировать»;
  - «Закрепить» / «Открепить»;
  - «Удалить».
- Удаление из окна взаимодействия использует тот же application-flow, что и существующее удаление свайпом.
- Закрепление реализовано на уровне presentation-состояния и не добавляется в domain финансовых данных.
- Закреплённые строки отображаются первыми внутри своего блока.
- Индекс финансовой стабильности остаётся полностью доступным только для просмотра.
- Обновлён Design System: отдельное оформление трёх действий окна взаимодействия, без CSS внутри механики.
- Вибрация долгого нажатия сохранена.

## Архитектура

- Domain не изменён.
- Application используется для существующего удаления.
- Presentation отвечает только за состояние взаимодействия и порядок отображения закреплённых строк.
- Design System содержит стили окна взаимодействия.

## Результат

Механика взаимодействия со строкой теперь единая для всех пяти редактируемых финансовых блоков и не дублирует логику удаления.
