# Сессия разработки — 05.10.2026, 12:40:21 (Москва)

## Изменено

- В форме добавления актива заменён обычный select ликвидности на один iOS-style switch.
- Switch имеет два состояния: «Ликвидный» и «Неликвидный».
- Состояние отображается одним бегунком и одной подписью; два отдельных переключателя не используются.
- По умолчанию новый актив создаётся в состоянии «Ликвидный».
- Выбранное состояние передаётся через application layer в Domain как liquidity.
- Добавлен отдельный компонент Design System: source/design/components/liquidity.switch.css.
- Компонент зарегистрирован через source/design/design.css.
- Добавлена доступность: role=switch, aria-checked, aria-label.
- Сохранены существующие поля «Актив», «Сумма» и кнопка «Добавить».

## Изменённые файлы

- source/presentation/finance/finance.js — Version 2.2
- source/design/design.css
- source/design/components/liquidity.switch.css — Version 1.1

## Зафиксировано

Механика пользовательского добавления актива:

Актив → Сумма → Ликвидность [один switch] → Добавить

## Одобрено пользователем

- Один бегунок.
- Положение бегунка определяет ликвидность.
- Текст состояния меняется: «Неликвидный» ↔ «Ликвидный».
- Визуальная модель ориентирована на системный switch iPhone.
