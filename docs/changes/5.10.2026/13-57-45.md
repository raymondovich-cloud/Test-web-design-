# Изменение: редактирование активов через long press

**Дата:** 05.10.2026  
**Время (Москва):** 13:57:45  
**Статус:** реализовано по согласованному решению.

## Изменено

- Добавлена операция редактирования актива в Domain.
- Добавлен Application-bridge для обновления актива.
- Добавлена отдельная presentation-механика assets.edit.js.
- Для строк блока «Активы» добавлен long press.
- После удержания появляется компактное контекстное действие «Редактировать».
- Добавлена короткая haptic-вибрация при срабатывании long press, если её поддерживает браузер.
- Добавлена плавная анимация появления контекстного действия.
- Добавлено редактирование названия, суммы и ликвидности актива.
- После сохранения строка и общий итог активов обновляются без полного перерендера страницы.
- Существующая механика свайпа влево и удаления не изменялась.
- Добавлена плавная анимация окна редактирования в стиле LifeGame.

## Архитектурные границы

- Данные изменяются через Domain → Application → Presentation.
- Domain не получает доступа к Memory.
- После изменения актива сохраняется существующая event-driven цепочка finance.assets.state.changed → Memory.
- Telegram-like interaction реализована в Presentation и Design System.

## Проверка

Проверены актуальные версии Domain, Application, Finance Presentation и новой presentation-механики редактирования после внесения изменений.
