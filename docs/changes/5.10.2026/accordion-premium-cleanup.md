# Изменение: премиальные аккордеоны без "+ / −"

Дата: 05.10.2026

## Изменено
- Убраны визуальные индикаторы "+ / −" из заголовков финансовых блоков.
- Сохранена интерактивность раскрытия и сворачивания блоков по нажатию на строку.
- Аккордеон переведён с трёхколоночной композиции на две колонки: номер + содержимое.
- Добавлены корректные версии файлов: finance.js 1.17, accordion.css 1.7.
- Создана резервная ветка: `backup/accordion-with-plus-before-premium-cleanup`.

## Принцип Design System
Интерактивность не должна обозначаться лишними символами, если она очевидна из композиции интерфейса. Для премиального LifeGame аккордеоны используют самоочевидную строку блока без "+ / −".

## Не изменено
- Логика открытия и закрытия блоков.
- Данные и бизнес-логика Finance.
- Domain, Memory, Application, Index, Profile и глобальная навигация.

## Статус
Изменение внесено в `main`.
