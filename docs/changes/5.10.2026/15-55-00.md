# Изменение — 5.10.2026 15:55 (МСК)

## Исправлено

Повторное появление бага, при котором после авторизации взаимодействие со строкой открывало окно создания аккаунта до перехода в другой модуль.

### Причина

Web shell мог получить временно пустую сессию во время гидрации Supabase Auth и преждевременно переключить интерфейс в public mode. После перехода в Health/Development выполнялась новая проверка сессии, поэтому проблема исчезала.

### Решение

`platforms/web/web.js` обновлён до Version 2.8:

- добавлена короткая повторная проверка сессии при старте/маршрутизации;
- используются интервалы 120 / 240 / 400 мс;
- найденная валидная сессия сразу фиксирует `authenticationEstablished`;
- временный null session больше не должен переводить авторизованного пользователя в public shell.

Функциональность редактирования, удаления, закрепления и визуальный overlay не изменялись.
