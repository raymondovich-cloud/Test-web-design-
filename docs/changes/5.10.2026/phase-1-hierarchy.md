# Изменения — Phase 1: Hierarchy

Дата: 05.10.2026 (МСК)

## Изменено

- Уточнена типографическая иерархия Design System.
- Добавлены семантические токены:
  - interface;
  - section;
  - value;
  - display.
- Усилен визуальный приоритет основных финансовых значений.
- Заголовки финансовых подблоков получили более выраженный уровень над описаниями.
- Описания подблоков сохранены как вторичный контекст и не усилены до уровня заголовков.
- Номер подблока переведён из визуального контейнера в тихую metadata-навигацию.
- Улучшен вертикальный ритм заголовков и описаний accordion.
- Для статистических значений применена единая semantic value hierarchy.
- Дата среза ликвидных средств снижена до metadata-уровня.

## Не изменено

- Цветовая концепция LifeGame.
- Согласованные описания всех шести финансовых блоков.
- Отказ от визуального «+».
- Разделительная линия заголовка открытого подблока, проходящая по всей ширине.
- Бизнес-логика Finance.
- Domain / Application / Memory.
- Формулы FSI 2.1.
