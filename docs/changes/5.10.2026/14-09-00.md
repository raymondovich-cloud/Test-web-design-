# Изменение: корректировка Telegram-like context menu для активов

**Дата:** 05.10.2026  
**Время (Москва):** 14:09:00  
**Статус:** реализовано.

## Изменено

- Убраны стили context menu из `list.css`.
- Создан отдельный Design System-компонент `context-menu.css`.
- Меню больше не позиционируется по центру строки.
- Меню теперь появляется около точки удержания пальца, по модели контекстного меню Telegram.
- Добавлено ограничение позиции по границам viewport, чтобы меню не уходило за экран.
- Сохранена плавная scale/opacity-анимация.
- Визуал меню переведён с обычного чёрного фона на существующие premium gradient tokens LifeGame с оранжевым акцентом.
- Существующая механика свайпа удаления не изменялась.

## UX-принцип

Long press должен создавать ощущение контекстного действия непосредственно в месте взаимодействия пользователя, а не открывать кнопку в геометрическом центре строки.
