# Исправление градиента SYSTEM ONLINE — применение к текстовому элементу

- Дата и время: 13.10.2026, 13:30 MSK (UTC+03:00).
- Запрос: использовать в SYSTEM ONLINE именно тот градиент, который отображается на заголовке «Тренировки» в разделе «Здоровье».
- Причина предыдущего результата: текст SYSTEM ONLINE находится во вложенном `span`, а градиент был назначен родительскому flex-элементу `.system-status`. В отличие от заголовка «Тренировки», текст был вложенным, поэтому фон с `background-clip: text` не обрезался по его глифам корректно.
- Изменённые файлы:
  - `source/design/components/header.css`: Version 1.2 → 1.3.
  - `source/design/design.css`: Version 4.29 → 4.30; cache-busting для `header.css` обновлён.
  - `platforms/web/index.html`: Version 1.41 → 1.42; cache-busting для Design System обновлён.
- Изменение: градиент `--gradient-text-premium` и свойства `background-clip: text`, `-webkit-background-clip: text`, `-webkit-text-fill-color: transparent` назначены непосредственно текстовому элементу `.system-status > span:not(.status-dot)`. Цвет индикатора-точки не изменён.
- Архитектурное решение: повторно использован тот же токен и механизм отрисовки текста, что применяются к заголовку «Тренировки» через глобальное правило `#app h1, #app h2, #app h3` в `source/design/foundation/base.css`. Новые токены и зависимости не добавлены.
- Проверка: CSS и ссылки кеширования сверены в актуальной тестовой ветке. Визуальный результат на опубликованной странице и завершение GitHub Actions требуют внешней проверки.
- Статус: исправлено в тестовой ветке; `main` не изменяется.
