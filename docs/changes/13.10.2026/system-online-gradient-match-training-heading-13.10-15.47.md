# Точное совпадение градиента SYSTEM ONLINE с заголовком «Тренировки»

- Дата и время: 13.10.2026, 15:47 MSK (UTC+03:00).
- Запрос: цвет и градиент надписи SYSTEM ONLINE в шапке должны визуально совпадать с заголовком «Тренировки» под меткой TRAINING в нижнем блоке раздела «Здоровье».
- Проверка реализации: заголовок «Тренировки» — это элемент `h3.health-overview-section__title`; глобальное правило Design System применяет к нему `--gradient-text-premium` через `background-clip: text`. Надпись SYSTEM ONLINE — вложенный span внутри flex-контейнера шапки. Ранее токен уже совпадал, но градиент рисовался в области шириной самого короткого текста, поэтому визуальное распределение цветов отличалось от заголовка.
- Изменённые файлы:
  - `source/design/components/header.css`: Version 1.3 → 1.4.
  - `source/design/design.css`: Version 4.30 → 4.31; обновлён cache-busting для header.css.
  - `platforms/web/index.html`: Version 1.42 → 1.43; обновлён cache-busting для Design System.
- Решение: сохранён тот же токен `--gradient-text-premium`; для SYSTEM ONLINE задана ширина области градиента, близкая к ширине текстовой области заголовка «Тренировки» в карточке Health. Для узких экранов и экранов шире 520 px применены соответствующие размеры. Позиция, размеры и цвет белой точки-индикатора не меняются; сам заголовок «Тренировки» и его стили не изменяются.
- Архитектура: изменена только презентационная часть Design System. Бизнес-логика, данные, зависимости и структура модулей не менялись.
- Проверка публикации: после коммита необходимо подтвердить запуск и успешное завершение GitHub Pages workflow; визуальное совпадение следует проверить на опубликованной тестовой странице.
- Статус: исправление внесено в тестовую ветку `chore/design-repo-bootstrap`; `main` не изменяется.
