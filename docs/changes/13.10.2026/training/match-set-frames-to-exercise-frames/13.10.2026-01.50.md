# Рамки подходов по размеру рамок упражнений — 13.10.2026, 01:50 MSK (UTC+03:00)

## Пользовательский запрос
В активной тренировке рамки подходов должны иметь такой же размер, оформление и зазоры, как рамки упражнений в свёрнутом состоянии.

## Анализ
- Отображение активной тренировки уже реализовано в `source/presentation/training/training-session.js`: раскрытие происходит внутри списка, четыре подхода предусмотрены по умолчанию, а добавление подхода и отметка выполнения уже работают.
- Причина несоответствия находится в CSS: строки подходов оформлены как разделители внутри карточки, а не как самостоятельные рамки; у них отсутствуют общий фон, рамка, скругление и тень.
- Для выполнения запроса достаточно изменить Design System. JavaScript, прикладные сценарии, доменную логику и сохранение данных менять не требуется.

## Изменения
- `source/design/patterns/training.css`: версия 3.43 → 3.44. Для свёрнутых упражнений и рамок подходов установлен общий размер по высоте; при раскрытии рамка упражнения сохраняется у заголовка, а подходы отображаются самостоятельными рамками на всю ширину с одинаковыми отступами между ними. Использованы существующие токены рамок и фона, добавлены адаптивные правила для узких мобильных и широких экранов.
- `source/design/design.css`: версия 4.16 → 4.17; обновлён cache-busting параметр импорта training.css на `20261013-0150`.
- JavaScript и бизнес-логика не менялись.

## Архитектурное решение
Визуальное поведение остаётся в Design System. Селектор `:has()` используется только для определения раскрытого упражнения по уже существующему состоянию `hidden`; новые зависимости и изменения DOM не добавляются.
