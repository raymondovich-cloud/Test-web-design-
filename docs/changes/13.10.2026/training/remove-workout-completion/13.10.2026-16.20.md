# Удаление функции завершения тренировки

- Удалена кнопка «ЗАВЕРШИТЬ ТРЕНИРОВКУ» и её обработчик из активной тренировки.
- Удалён пользовательский application-use-case `completeWorkout`; workflow больше не требует API-команду завершения.
- Сохранены запуск тренировки, запись подходов, восстановление активной тренировки и переход «Назад».
- Удалены связанные CSS-правила кнопки; статус обратной связи оставлен в активном экране.
- Доменный переход статуса и серверный API не удалялись: это отдельные нижележащие контракты/исторические данные, их удаление не требуется для исключения действия из пользовательского сценария.
- Обновлены version markers и cache-busting параметры Design System/Web entry point.
- Проверка: обновлены unit-тесты workflow; выполнение CI ожидается после коммита.
