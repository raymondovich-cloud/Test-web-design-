# Прозрачный фон кнопки завершения тренировки

- Дата: 13.10.2026.
- Пользователь сообщил, что после публикации кнопка по-прежнему выглядит залитой.
- Диагностика: предыдущий CSS содержал полупрозрачный оранжевый градиент в фоне кнопки. Это не соответствовало требованию оставить оформление рамочным.
- Исправление: фон активной кнопки заменён на полностью прозрачный; рамка, радиус, тень и размеры сохранены.
- Обновлены маркеры версий и cache-busting параметры для основного CSS и стилей тренировки.
- Изменённые файлы:
  - `source/design/patterns/training.css`: Version 3.37 → 3.38.
  - `source/design/design.css`: Version 4.8 → 4.9.
  - `platforms/web/index.html`: Version 1.34 → 1.35.
- Архитектура, DOM, размеры кнопки и логика завершения тренировки не менялись.
- Ветка: `chore/design-repo-bootstrap`. `main` не изменялась.
