# Тип тренировки в активной сессии

Дата и время: 13.10.2026, 14:25 MSK (UTC+03:00)

## Пользовательский запрос
В активной тренировке между заголовком LIFEGAME и ACTIVE SESSION отображать строку «Тип тренировки: …», определяемую по категориям добавленных упражнений.

## Реализация
- Активная сессия использует доменное правило классификации существующего модуля `workout-type.js`.
- В заголовок добавлена строка «Тип тренировки: Кардио тренировка», «Тип тренировки: Силовая тренировка», «Тип тренировки: Тренировка с собственным весом» или «Тип тренировки: Смешанная тренировка» в зависимости от категорий упражнений.
- Если список упражнений пуст, отображается безопасное значение «Не определён».
- Строка расположена перед ACTIVE SESSION; CSS-сетка сохраняет таймер справа и кнопку «Назад» отдельной строкой.
- Обновлена версия CSS-ресурса для сброса кэша тестовой публикации.
