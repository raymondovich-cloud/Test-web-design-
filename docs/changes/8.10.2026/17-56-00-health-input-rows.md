# Health Input Rows

**Дата:** 08.10.2026  
**Время:** 17:56:00 MSK (UTC+03:00)  
**Статус:** IMPLEMENTED / REQUIRES VERIFICATION

## Изменение

Строки ввода в управлении данными Health приведены к визуальному паттерну Finance.

## Что изменено

- Health numeric inputs используют общий Design System-класс `input-control`.
- Высота, внутренние отступы, фон, граница, радиус и focus-состояние синхронизированы с Finance.
- Подписи полей сохранены для Health, поскольку они необходимы для понятного ввода показателей.
- Checkbox «Тренировка сегодня» получил отдельное компактное отображение в той же визуальной системе.

## Ограничения

Изменена только presentation/design-часть Health. Семантика показателей, модель данных, сохранение и расчёт Health Index не изменялись.
