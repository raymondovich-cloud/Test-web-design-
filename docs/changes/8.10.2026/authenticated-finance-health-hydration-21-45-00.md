# Изменение: исправление гидратации Finance и Health после авторизации

Дата: 08.10.2026
Время: 21:45 МСК

## Причина
После успешной авторизации веб-runtime мог получить кратковременно пустую сессию при повторной проверке Supabase. При этом authenticationEstablished уже становился true, но activeUserId ещё оставался null. Авторизованный shell отображался без пользовательского приложения, поэтому Finance и Health выглядели пустыми.

## Изменения
- platforms/web/web.runtime.js — Version 5.7.
- После успешной авторизации runtime теперь дополнительно разрешает текущую сессию через существующий retry-механизм до рендера пользовательского модуля.
- activeUserId устанавливается из подтверждённой сессии до создания Finance/Health application.
- Добавлена диагностическая трассировка готовности авторизованной сессии.
- platforms/web/web.js — Version 5.6.
- Обновлён cache-busting runtime до 20261008-2140.
