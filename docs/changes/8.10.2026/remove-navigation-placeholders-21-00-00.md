# LifeGame — Удаление временных заглушек навигации
Дата: 08.10.2026

## Изменения
- Удалён предварительный рендер временных Finance/Health/Development/Profile заглушек из web bootstrap.
- Основной runtime теперь сразу отвечает за отрисовку выбранного модуля.
- При авторизованной навигации убран промежуточный preview перед гидрацией данных.
- Обновлена cache-busting версия web bootstrap.

## Результат
При переходе между разделами пользователь больше не должен видеть сначала временную заглушку, а затем настоящий раздел.

## Проверка
Изменения внесены в main. Финальная проверка фактического Safari/iPhone click-through выполняется после деплоя.
