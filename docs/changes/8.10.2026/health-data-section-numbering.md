# Изменение: нумерация блоков в редактировании Health

Дата: 08.10.2026

## Изменено

- В разделе редактирования данных Health каждому блоку присвоен номер в едином формате с Finance.
- Добавлена последовательная нумерация:
  - 01 — Восстановление
  - 02 — Активность
  - 03 — Тренировки
  - 04 — Питание
  - 05 — Образ жизни
  - 06 — Состояние тела
- Для отображения используется существующий компонентный стиль `accordion-index`, применяемый в Finance.
- Изменена сетка заголовка Health Data, чтобы номер располагался слева, название и описание — по центру, информационный tooltip — справа.
- Логика расчёта Health, сохранения данных и аналитики не изменялась.

## Изменённые файлы

- `source/presentation/health/health.js` — Version 2.1.
- `source/design/patterns/health.css` — Version 1.9.

## Результат

Редактирование Health теперь визуально использует ту же систему нумерации блоков, что и редактирование Finance.
