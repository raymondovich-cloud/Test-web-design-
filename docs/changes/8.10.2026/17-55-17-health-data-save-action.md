# Health Data Save Action

**Дата:** 08.10.2026  
**Время:** 17:55:17 MSK (UTC+03:00)  
**Статус:** IMPLEMENTED / REQUIRES VERIFICATION

## Изменение

Кнопка сохранения в управлении данными Health перенесена внутрь соответствующей категории, по аналогии с управлением данными Finance.

## Поведение

Каждая категория Health с ручными показателями теперь содержит собственную кнопку **«Сохранить»** внутри раскрытого блока.

Сохранение выполняется для выбранной категории, а не через одну общую кнопку вне списка категорий.

## Ограничения

Изменена presentation-логика формы в `source/presentation/health/health.js`. Модель данных, категории Health и расчёт Health Index не изменялись.
