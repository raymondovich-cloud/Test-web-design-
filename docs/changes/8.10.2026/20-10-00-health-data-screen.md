# Health Data Screen

**Дата:** 08.10.2026  
**Время:** 21:10:00 MSK (UTC+03)  
**Статус:** IMPLEMENTED / REQUIRES VERIFICATION

## Запрос

Сделать управление данными Health отдельным экраном по тому же UX-паттерну, который используется в Finance.

## Изменения

- Убрано inline-раскрытие формы управления данными на главной странице Health.
- Добавлен отдельный Health data screen.
- На главной странице Health действие изменено на «Открыть →».
- Добавлена навигация «← Health» для возврата.
- Существующая форма ручного ввода Health перенесена на отдельный экран без изменения полей и механизма сохранения.
- После сохранения пользователь возвращается на основной экран Health.
- Добавлены Health-specific стили отдельного экрана управления.

## Архитектурные решения

Изменение ограничено Presentation и Design System. Health Index, Application, Memory, Supabase и схема данных не изменялись.

UX-паттерн управления данными синхронизирован с Finance: основной экран → «Открыть» → отдельный экран управления → возврат в модуль.

## Верификация

Проверить: Health → «Открыть» → экран «Данные здоровья» → сохранить данные → возврат в Health → обновление Health Index.
