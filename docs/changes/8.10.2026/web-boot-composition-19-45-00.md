# LifeGame — исправление критического запуска Web Shell

Дата: 08.10.2026
Время: 19:45 MSK

## Проблема

При открытии LifeGame пользователь видел только статический header и нижнюю навигацию из четырёх кнопок. Центр приложения не отрисовывался.

## Диагностика

Установлено, что `platforms/web/web.js` имел статическую зависимость от composition root. Composition root импортирует Supabase Infrastructure, включая внешний ESM SDK. Ошибка загрузки или инициализации этой зависимости могла остановить выполнение всего entrypoint до первого вызова рендера.

В результате браузер оставлял только HTML-shell, который уже присутствует в `platforms/web/index.html`.

## Исправление

Изменён `platforms/web/web.js`:

- удалена статическая зависимость от composition root;
- запуск Web Shell сделан асинхронным;
- статический публичный Finance surface теперь отрисовывается до загрузки Infrastructure;
- composition root загружается через динамический `import()`;
- ошибка загрузки Infrastructure больше не скрывает уже отрисованный интерфейс;
- успешная загрузка composition root автоматически запускает обычную авторизацию и hydration;
- добавлена диагностика `composition.ready` / `composition.error`.

## Архитектурное соответствие

Изменение сохраняет Clean Architecture: composition root остаётся единственной точкой сборки Infrastructure, но теперь не является критической зависимостью первого кадра UI.
