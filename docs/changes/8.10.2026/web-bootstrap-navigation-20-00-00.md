# Изменение Web Bootstrap — 8.10.2026

## Время
20:00 (МСК)

## Проблема
После последнего bootstrap-фикса на экране появлялась только базовая финансовая секция. При сбое загрузки runtime навигация оставалась визуальной, но переходы между модулями не отрабатывали.

## Изменения
- Обновлён `platforms/web/web.js` до версии 5.1.
- Добавлен независимый fallback-рендер Finance, Health, Development и Profile.
- Навигация и `hashchange` теперь работают даже при полном отказе `web.runtime.js`.
- Сбой runtime больше не оставляет остальные модули пустыми.

## Архитектурная цель
Bootstrap остаётся минимальным и отказоустойчивым слоем запуска. Основная бизнес-логика не переносится в bootstrap; fallback используется только для сохранения работоспособности интерфейса при ошибке загрузки runtime.

## Статус
Изменение применено в main. Следующий шаг — проверить причину сбоя `web.runtime.js`, чтобы вернуть полноценные Finance/Health/Development/Profile, а не только fallback.
