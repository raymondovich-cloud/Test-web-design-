# Исправление аналитики Health — 8.10.2026

## Время
8.10.2026, 18:xx (МСК)

## Изменённый файл
- `source/presentation/health/section.analytics.js` — Version 1.4.

## Причина ошибки
Экран аналитики получал объект раздела из `HEALTH_DATA_SECTIONS`, где название хранится в поле `label`. Рендерер обращался к несуществующему `section.title.toUpperCase()`.

Из-за исключения рендеринг прекращался до `root.appendChild(page)`, поэтому после нажатия «Аналитика →» контейнер оставался полностью пустым.

## Исправление
- Добавлена нормализация метаданных раздела: `label` используется как основное название.
- Добавлен безопасный fallback на `title`.
- Добавлена проверка обязательного ключа раздела.
- Все обращения аналитики к ключу раздела используют нормализованный `sectionKey`.

## Результат
Аналитика теперь должна открываться для всех разделов Health и доходить до загрузки фактов из Health Application / Memory.
