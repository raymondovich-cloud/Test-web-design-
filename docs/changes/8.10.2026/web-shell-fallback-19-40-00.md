# Изменение Web Shell — 8.10.2026

Время: 19:40 (Москва)

## Изменено

- `platforms/web/web.js` — версия 4.8.
- Добавлен безопасный fallback при ошибке авторизованной гидратации пользовательских данных.
- Ошибка Finance/Health/Development/Profile больше не оставляет приложение только с шапкой и нижней навигацией.
- При сбое загрузки данных приложение сохраняет рабочий shell и показывает соответствующий безопасный экран модуля.

## Причина

Асинхронная ошибка после проверки авторизации могла прервать `renderApplicationShell()` до отрисовки содержимого модуля. В результате пользователь видел только шапку и четыре кнопки навигации.

## Статус

Исправление внесено в `main`. Следующий шаг — проверить опубликованную версию сайта и отдельно устранить исходную причину ошибки гидратации, если она сохраняется.
