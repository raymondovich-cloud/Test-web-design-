# Изменение: индекс первым для авторизованного пользователя

Дата: 08.10.2026
Время: 21:05

## Изменено

- Presentation-заголовок Finance/Health/Development теперь является публичным preview-слоем.
- Для авторизованного пользователя этот описательный блок скрывается.
- Первым визуальным блоком каждого модуля становится соответствующий индекс.
- Для неавторизованного пользователя презентационный блок сохраняется.
- Состояние авторизации централизованно передаётся из web runtime в presentation.
- Методология индексов, расчёты, данные и Interaction Engine не изменялись.

## Версии

- Finance 7.10
- Health 2.2
- Development 1.5
- Web Runtime 5.4

## Архитектура

Изменены только presentation/runtime-контуры отображения. Данные и domain/application-логика не затронуты.
