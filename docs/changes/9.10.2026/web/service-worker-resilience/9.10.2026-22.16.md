## Изменение

- Ошибка открытия Cache Storage больше не препятствует сетевому запросу.
- Ошибка записи в кэш не перехватывается как сетевая ошибка и не заменяет успешный ответ.
- Резервный ответ из кэша используется только после реального сбоя сети; ошибка чтения кэша не подменяет исходную сетевую ошибку.
- Добавлены автоматические тесты network-first, обновления кэша, offline fallback, ошибок Cache Storage, правил Cache-Control/Vary и исключения HTML/API/cross-origin.
- Проверка Service Worker подключена к существующему CI без внешних зависимостей.

## Архитектурные решения

- Service Worker остаётся отдельным платформенным техническим компонентом.
- Cache Storage — необязательная оптимизация, а не обязательная зависимость загрузки.
- Проверка заголовка Set-Cookie не используется как защитный барьер: этот заголовок может быть недоступен JavaScript в браузере.
- Пользовательские API и HTML по-прежнему исключены из перехвата.
