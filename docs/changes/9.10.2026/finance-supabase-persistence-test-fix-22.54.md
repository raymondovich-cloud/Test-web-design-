## Что изменено

В тесте восстановления Finance memory после повторного создания использовалось имя `recreatedMemoryA`, хотя экземпляр объявлен как `recreatedMemory`. Все обращения к экземпляру приведены к имени объявленной переменной.

## Причина

Ошибка `ReferenceError: recreatedMemoryA is not defined` останавливала интеграционный тест до выполнения последующих проверок гидратации и изоляции пользователей.

## Архитектурные решения

- Исправлен только тестовый сценарий; бизнес-логика, инфраструктурная реализация и схема базы данных не изменялись.
- Сохранена граница ответственности: проверка реального Supabase persistence остаётся в infrastructure integration test.
- Ветка `main` используется только для этого исправления и подтверждения CI. Дальнейшая разработка планируется в тестовой веб-версии; отдельные ветки, PR и Test-web не изменяются этой операцией.

## Проверка

- Статическая проверка: все обращения используют объявленный идентификатор `recreatedMemory`.
- Автоматический результат GitHub Actions будет проверен после коммита.
