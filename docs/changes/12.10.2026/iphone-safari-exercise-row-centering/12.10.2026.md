# Исправление центрирования строк упражнений на iPhone — 12.10.2026

## Причина
Предыдущая версия рассчитывала ширину строк относительно viewport, хотя они находятся внутри контейнера тренировки с собственными горизонтальными отступами. Это не обеспечивало надёжного центрирования в Safari на iPhone.

## Изменения
- Контейнер упражнений получил ширину 100% доступной внутренней области и центрирование дочерних элементов через CSS Grid.
- Строки текущего и последующих упражнений используют ширину фактической области содержимого и ограничены её границами.
- Сброшены потенциальные смещения через left/right/transform и конкурирующие внешние отступы.
- JavaScript и бизнес-логика не менялись.

## Среда
- CSS: версия 3.54.
- Репозиторий: raymondovich-cloud/Test-web-design-
- Ветка: chore/design-repo-bootstrap.
- Основная ветка не изменялась.

## Проверка
Изменение закоммичено. Визуальную проверку на реальном Safari iPhone нужно подтвердить после публикации.

## Небольшое увеличение ширины — версия 3.55
- Область строк упражнений расширена на 0,75 rem суммарно относительно прежней внутренней ширины.
- Центрирование сохранено: контейнер имеет автоматические горизонтальные отступы, строки остаются шириной 100% этого контейнера.
- Добавлено ограничение по ширине viewport для Safari на iPhone, чтобы строки не подходили вплотную к краям экрана.
- JavaScript, разметка и бизнес-логика не менялись.
