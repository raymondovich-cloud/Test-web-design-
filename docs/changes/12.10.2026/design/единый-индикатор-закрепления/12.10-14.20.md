# Единый индикатор закрепления — Change Log

- Дата: 12.10.2026
- Ветка: `feature/pwa-static-cache`
- Область: Presentation / Design System

## Причина
Унифицировать визуальный индикатор закрепления во всех местах, где эта функция уже предусмотрена, используя финансовую карусель как эталон.

## Изменения
- Добавлен общий presentation-компонент `createPinIndicator`: точка, подпись и SVG-булавка.
- Финансовая карусель, финансовые строки, строки финансовой аналитики и сохранённые тренировки используют общий компонент.
- Общие стили индикатора вынесены в Design System; размеры индикатора адаптируются к контексту строки.
- Обновлены версии изменённых файлов и cache-busting CSS imports.
- Механика закрепления, лимиты, сортировка и persistence не изменялись.

## Проверки
- Проверена доступность всех ожидаемых фрагментов перед изменением.
- Статическая проверка после commit запланирована через GitHub Actions.
- Визуальная проверка на iPhone/Safari требует проверки опубликованного preview.
