# Упрощение водяного знака здоровья

- Дата: 12.10.2026
- Время: 16:05 MSK (UTC+03:00)

## Причина
Предыдущая версия водяного знака визуально воспринималась как фигура с дополнительными руками. Дополнительно необходимо исключить показ старого SVG из браузерного кеша.

## Изменения
- `source/design/assets/watermark-health.svg` — Version 4.1: перерисован силуэт с двумя согнутыми руками, каждая изображена единственным контуром; корпус больше не содержит дублирующих боковых контуров рук.
- `source/design/patterns/watermarks.css` — Version 1.5: обновлён URL SVG для обхода кеша.
- `source/design/design.css` — Version 4.3: обновлена версия импорта водяных знаков.
- `platforms/web/index.html` — Version 1.28: обновлена версия CSS для обхода кеша.

## Границы
Изменения ограничены SVG и Design System. Финансовый и developmental watermark, бизнес-логика, авторизация, API и база данных не изменялись. Изменения записаны в `feature/pwa-static-cache`; `main` не менялась.

## Проверки
Нужно дождаться CI и публикации тестовой среды, затем проверить результат на iPhone Safari.
