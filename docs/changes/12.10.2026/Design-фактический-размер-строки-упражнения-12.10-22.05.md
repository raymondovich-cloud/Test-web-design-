# Design — фактический размер строки упражнения

- Дата и время: 12.10.2026, 22:05 MSK (UTC+03:00)
- Пользовательский запрос: после предыдущего изменения размер строк упражнений визуально не изменился; строка должна совпадать по габаритам с кнопкой завершения тренировки.
- Изменённые файлы:
  - `source/design/patterns/training.css` — Version 3.43 → 3.44
- Описание: размеры назначены всей компактной карточке, а не только верхней строке. На мобильном breakpoint карточка растягивается на полную ширину области кнопки, компенсируя горизонтальные отступы контейнера; минимальная высота согласована с кнопкой завершения.
- Причина: предыдущее правило меняло только внутренний элемент и не компенсировало горизонтальные отступы контейнера; поэтому внешние габариты карточки могли оставаться визуально прежними.
- Архитектурное решение: изменён только CSS; без изменения логики тренировки и новых зависимостей.
- Статус: IMPLEMENTED; требуется проверка после публикации на устройстве.
