# Исправление модального окна настроек профиля

- Дата: 12.10.2026
- Время: 17:00 MSK (UTC+03:00)

## Причина
Модальное окно настроек создавалось внутри секции профиля, которая находится в `.app-shell` с `overflow:hidden`. Это могло ограничивать слой модального окна и приводить к тому, что нижняя навигация визуально накладывалась на окно настроек.

## Изменения
- `source/presentation/profile/profile.js` — Version 1.8: модальное окно настроек теперь добавляется непосредственно в `document.body`, а не внутрь секции профиля.
- `source/design/components/profile.css` — Version 1.3: повышен слой модального окна до `z-index: 2000`, добавлена изоляция stacking context.
- `source/design/design.css` — Version 4.5: обновлён cache-busting CSS профиля.
- `platforms/web/index.html` — Version 1.30: обновлён URL Design System для сброса кеша.

## Границы
Изменение затрагивает только представление профиля и CSS. Бизнес-логика, API, авторизация и база данных не изменялись. Работа выполняется в `feature/pwa-static-cache`; ветка `main` не меняется.

## Проверки
Необходимо дождаться CI и обновления тестовой среды, затем проверить модальное окно на iPhone Safari: нижняя навигация должна оставаться в своём обычном месте и не накладываться на содержимое окна.
