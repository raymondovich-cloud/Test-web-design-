# Размер кнопки «Добавить подход» — версия 3.59

- Дата: 12.10.2026
- Файл: `source/design/patterns/training.css`
- Версия CSS: 3.59

## Изменение
- Кнопка «Добавить подход» получила высоту 3.8rem — такую же, как строки упражнений и подходов.
- Ширина кнопки занимает 100% доступной ширины контейнера строки.
- Уменьшены внутренние отступы и размер значка «+», чтобы содержимое аккуратно помещалось в новую высоту.
- Для экранов шириной до 390px сохранена та же высота с более компактными внутренними параметрами.

## Границы изменения
- Изменён только CSS активной тренировки.
- JavaScript, бизнес-логика, данные и сохранение подходов не затрагивались.
- Визуальная проверка в мобильном браузере после публикации ещё требуется.
