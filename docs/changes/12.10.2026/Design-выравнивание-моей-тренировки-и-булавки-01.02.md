# Design — выравнивание заголовка и метки закрепления

- Дата и время: 12.10.2026, 01:02 MSK (UTC+03:00)
- Пользовательский запрос: «Хорошо моя тренировка и закреплена должны быть на одном уровне. Сейчас моя тренировка ниже чем плашка закреплена».
- Изменённые файлы:
  - `source/design/patterns/training.css` — Version 3.16 → 3.17
  - `source/design/design.css` — Version 3.5 → 3.6
- Изменение: заголовок закреплённой тренировки больше не смещается вниз; справа для метки «Закреплена» резервируется место, чтобы заголовок и метка находились на одном горизонтальном уровне без наложения.
- Причина: верхний отступ содержимого закреплённого элемента создавал визуальное несовпадение заголовка и метки.
- Архитектурное решение: изменена только Design System CSS; бизнес-логика, структура данных и механика закрепления не затрагивались.
- Статус: внесено в рабочую ветку; ожидает проверки CI и тестовой публикации.
