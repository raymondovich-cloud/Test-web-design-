# Изменение: уменьшение кнопок создания в разделе «Тренировка»

- Дата и время: 12.10.2026, 15:00 MSK (UTC+03:00)
- Пользовательский запрос: «Плюсики, которые добавляют новую тренировку и новое упражнение нужно сделать еще меньше, такого же размера как сделана подсказка в разделе активы. И плюсик внутри этого круга должен располагаться ровно по центру».
- Область: Presentation / Design System — только визуальные параметры кнопок.
- Изменённые файлы:
  - `source/design/patterns/training.css`: Version 3.12 → 3.13.
  - `docs/changes/12.10.2026/training/smaller-centered-create-buttons/12.10.2026-15.00.md`: новый Change Log.
- Изменение: обе кнопки создания тренировки и упражнения используют общий селектор `.training-saved-resources__create`; диаметр круга уменьшен с 2.25rem до 1.5rem, размер знака «+» — с 1.5rem до 1rem. Выравнивание переведено на flex с `align-items: center` и `justify-content: center`, чтобы центрировать знак по обеим осям.
- Причина: сделать элементы компактнее и визуально аккуратнее, не затрагивая обработчики и поведение создания.
- Архитектурное решение: изменён только CSS в Design System; JavaScript, бизнес-логика и зависимости не затронуты.
