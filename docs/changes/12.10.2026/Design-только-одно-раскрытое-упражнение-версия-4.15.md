# Дизайн тренировки: раскрыто только одно упражнение

- Дата: 12.10.2026
- Файл: `source/presentation/training/training-session.js`
- Версия: 4.15

## Изменение
При раскрытии упражнения предыдущий раскрытый блок автоматически сворачивается. Одновременно раскрытым может быть только одно упражнение. Повторное нажатие на открытое упражнение сворачивает его. Сохранены текущая логика активного упражнения, клавиатурное управление и работа подходов.

## Область изменений
Изменена только логика раскрытия/сворачивания в тестовой ветке `chore/design-repo-bootstrap`. CSS, данные тренировки и основная ветка `main` не менялись.

## Проверка
Изменение внесено в обработчик переключения раскрытия. После завершения публикации требуется визуально проверить поведение на тестовой странице.
