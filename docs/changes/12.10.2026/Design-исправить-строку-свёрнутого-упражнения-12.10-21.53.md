# Design — исправить строку свёрнутого упражнения

- Дата и время: 12.10.2026, 21:53 MSK (UTC+03:00)
- Пользовательский запрос: «Первое упражнение свернуто, но сама его строка не отображается. Отображается только стрелка, что бы его развернуть».
- Изменённые файлы:
  - `source/design/patterns/training.css` — Version 3.39 → 3.40
- Описание: исправлена сетка верхней строки текущего упражнения. Кнопка раскрытия занимает ширину по содержимому, заголовок получает оставшееся пространство.
- Причина: порядок DOM — сначала кнопка раскрытия, затем заголовок — не совпадал с порядком колонок CSS. Широкая первая колонка назначалась кнопке, а заголовок сжимался в узкую колонку.
- Архитектурное решение: изменён только CSS Design System; состояние сворачивания, обработчики, строки подходов и прикладная логика не затронуты. Основная ветка не изменялась.
- Статус: IMPLEMENTED; требуется визуальная проверка опубликованной тестовой сборки.
