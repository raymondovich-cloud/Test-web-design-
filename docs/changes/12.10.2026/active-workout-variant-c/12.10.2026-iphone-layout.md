# Изменение мобильной вёрстки активной тренировки

Дата: 12.10.2026

## Изменения
- Перестроена верхняя область активной тренировки для узкого viewport iPhone: кнопка возврата, статус и название теперь идут вертикально.
- Исправлена структура сетки прогресса: счётчик, полоса и процент размещаются в одной строке.
- Уточнены размеры заголовка упражнения, метаданных, иллюстрации и индикатора подходов.
- Добавлены ограничения ширины и защита от переполнения для карточек подходов и полей ввода.
- Нижняя кнопка закреплена с учётом `env(safe-area-inset-bottom)`; контейнер учитывает динамическую высоту viewport через `svh`/`dvh`.
- Обновлён cache-busting импорт `training.css`.

## Архитектура и риски
Изменены только Presentation styles и импорт Design System. Domain, Application, persistence и механика записи подходов не менялись. Новые зависимости не добавлялись.

## Проверка
GitHub Pages deployment проверяется после коммита. Визуальную проверку на реальном iPhone следует выполнить по тестовой ссылке после публикации.
