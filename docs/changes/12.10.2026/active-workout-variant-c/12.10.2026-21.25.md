# Точное воспроизведение активной тренировки — Variant C

- Дата: 12.10.2026 (MSK)
- Референс: пользовательский скриншот активной силовой тренировки.
- Рабочий репозиторий: `raymondovich-cloud/Test-web-design-`
- Рабочая ветка: `chore/design-repo-bootstrap`

## Разбор референса
1. Верхний блок: круглая кнопка возврата с тонким оранжевым свечением; оранжевая метка `ACTIVE SESSION`; заголовок тренировки.
2. Прогресс сессии: слева текст «N из M подходов», посередине тонкий горизонтальный индикатор с оранжевым заполнением, справа процент.
3. Текущее упражнение: крупный заголовок; строка рабочего веса, повторений и количества подходов; контурная схема мышц с выделением целевой зоны; вертикальные оранжевые/тёмные отметки подходов.
4. Подходы: самостоятельные горизонтальные капсульные строки; круглый номер; подпись «ПОДХОД»; отдельные подписанные поля «ПОВТОРЫ» и «ВЕС»; круглый чекбокс справа. Текущий визуально выделен оранжевой обводкой, выполненные подходы имеют оранжевые отметки.
5. Добавление подхода: отдельная крупная капсула с круглым плюсом слева и стрелкой справа.
6. Следующие упражнения: компактные карточки с порядковым номером, названием, прогрессом и стрелкой; подробности свёрнуты до раскрытия.
7. Завершение: широкая оранжевая кнопка-капсула в нижней закреплённой зоне; системная навигация приложения скрывается, чтобы не конфликтовать с экраном тренировки.
8. Мобильная композиция: чёрный фон, тонкие серые границы, тёплое оранжевое свечение, safe-area iPhone, адаптивные размеры для узких экранов.

## Архитектура и механика
- Бизнес-правила и Application API сохранены; новые библиотеки не добавлялись.
- Сохранение подхода остаётся за `application.recordSet`, завершение — за `application.completeWorkout`.
- Добавление подхода меняет план текущего представления существующим механизмом.
- Режим полного экрана включается на время активной сессии и снимается disposer-функцией при выходе из компонента.
- `main` не изменялась.

## Проверка
- Изменения внесены в тестовую ветку. После фиксации требуется подтвердить GitHub Actions и реальную публикацию GitHub Pages.
- Визуальное совпадение на устройстве требует финальной проверки в Safari на iPhone; до неё абсолютное 100% совпадение не заявляется.
