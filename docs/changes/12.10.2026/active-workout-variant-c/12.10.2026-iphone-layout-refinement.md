# Уточнение мобильной вёрстки активной тренировки

Дата: 12.10.2026

## Изменения
1. Уменьшен размер круглой кнопки возврата и размер самой стрелки.
2. Заголовок `ACTIVE SESSION` и название тренировки размещены справа от кнопки возврата в одной строке компоновки.
3. Прогресс тренировки перестроен в две строки: счётчик и процент сверху, интерактивная полоса прогресса снизу. Сохранён нативный элемент `<progress>` и его текущее значение.
4. Уменьшены размеры названия упражнения, счётчика подходов, метаданных подходов и повторений; сокращены промежутки.

## Архитектура
Изменения только в CSS Design System. Domain/Application и обработчики записи подходов не изменялись. Новые зависимости не добавлялись.

## Проверка
Ожидается завершение GitHub Actions Web Deploy; затем требуется визуальная проверка в Safari на iPhone.
