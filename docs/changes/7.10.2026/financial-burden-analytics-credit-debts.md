# Financial Burden Analytics — Credit Products / Debts

Дата: 07.10.2026

## Изменение

Раздел «Аналитика» финансовой нагрузки приведён к паттерну аналитики активов и разделён на две категории:

- «Кредитные продукты» — записи с `isCreditProduct === true`.
- «Долги» — записи без кредитного продукта.

Для обеих категорий сохранены:

- отображение последних 3 записей в превью;
- «Открыть все» при наличии более 3 записей;
- закрепление;
- редактирование;
- удаление свайпом;
- оранжевая булавка;
- существующий формат суммы, платежа и процентной ставки для кредитных продуктов.

## Архитектура

Изменена только презентационная логика `source/presentation/finance/section.analytics.js`.

Расчёты финансовой нагрузки, FSI 2.1, модель кредитного продукта и хранение данных не изменялись.
