# Изменение — корректировка исторического сравнения FSI

**Дата:** 07.10.2026  
**Время (МСК):** после 17:00

## Изменённые файлы

- `source/application/finance/finance.js` — историческая база для сравнения больше не зависит только от `assets`; проверяются все четыре финансовые коллекции.
- `source/application/finance/finance.diagnosis.js` — исправлены падежи названий факторов для корректного русского текста.

## Что исправлено

Ранее предыдущий FSI за месяц формировался только при наличии исторического snapshot по `assets`. Из-за этого пользователь мог иметь историю доходов, долгов или обязательных расходов, но интерфейс сообщал, что истории недостаточно.

Теперь историческая база считается существующей, если на дату сравнения доступен snapshot хотя бы одной из финансовых коллекций:

- assets;
- actual-earnings;
- financial-burden;
- mandatory-expenses.

Для каждой коллекции продолжает использоваться её собственный последний snapshot, доступный на дату сравнения.

## Языковое исправление

Было:

> Текущим ограничивающим фактором остаётся финансовой подушки.

Стало:

> Текущим ограничивающим фактором остаётся финансовая подушка.

Для факторных изменений сохранён родительный падеж, например: «изменение финансовой подушки».

## Ограничения этапа

- Формула FSI 4.1 не изменялась.
- Веса FSI не изменялись.
- Раскрывающаяся подробная диагностика пока не перерабатывалась.
