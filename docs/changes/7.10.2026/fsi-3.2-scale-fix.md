# Исправление шкалы FSI 3.2

**Дата:** 07.10.2026
**Время:** 15:42:12 MSK
**Статус:** IMPLEMENTED

## Причина

FSI рассчитывается во внутренней шкале 0–100, однако финальное ограничение использовало `clamp(value)`, где значение по умолчанию ограничивается диапазоном 0–1.

Из-за этого корректный рассчитанный FSI выше 1 принудительно превращался в `1.0`. Presentation затем корректно переводил внутреннюю шкалу 0–100 в пользовательскую 0–1000, поэтому на экране появлялось `10/1000`.

## Изменённый файл

- `source/index/finance/finance.index.js` — Version 3.1 → 3.2

## Исправление

Финальное значение теперь ограничивается явным диапазоном FSI:

`clamp(value, FSI_LIMITS.minimum, FSI_LIMITS.maximum)`

То есть:

- внутренняя шкала: 0–100;
- UI: FSI × 10 → 0–1000;
- диагностические компоненты остаются в шкале 0–100.

## Важно

Формула FSI 3.1, веса, component floor 0.05 и risk gates не изменялись. Исправлена только ошибочная финальная нормализация результата.
