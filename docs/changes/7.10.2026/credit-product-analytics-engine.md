# Credit Product Analytics Engine

Дата: 07.10.2026

## Изменения

Добавлен доменный расчёт кредитного продукта:

- ежемесячное начисление процентов;
- ежемесячный платёж;
- остаток долга;
- срок до полного погашения;
- общая сумма процентов;
- общая сумма выплат;
- определение ситуации, когда платёж не покрывает начисленные проценты.

Расчёт использует годовую ставку, преобразованную в месячную, без изменения FSI 2.1.

В аналитике финансовой нагрузки для кредитных продуктов теперь дополнительно отображается:

- ориентировочный срок закрытия;
- ориентировочная переплата.

Для ситуации, когда платёж не покрывает проценты, отображается соответствующее предупреждение.
