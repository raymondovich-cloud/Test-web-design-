# Изменение: кредитные продукты в финансовой нагрузке

Дата: 07.10.2026
Время: 13:21:53 MSK

## Изменено

- В блоке «Финансовая нагрузка» добавлен переключатель «Кредитный продукт».
- При выключенном переключателе запись сохраняется как обычное обязательство без регулярного платежа и процентной ставки.
- При включенном переключателе появляются поля:
  - «Регулярный платёж»
  - «Процентная ставка, % годовых»
- В модель финансовой нагрузки добавлены:
  - `isCreditProduct`
  - `payment`
  - `interestRate`
- Существующая механика долга сохранена.
- В редактирование записей добавлен тот же переключатель и зависимые поля.
- В аналитике финансовой нагрузки отображаются регулярный платёж и ставка только для кредитных продуктов.
- FSI не изменялся. Текущая формула продолжает использовать существующую задолженность и регулярные платежи.
- В Supabase добавлены поля `is_credit_product` и `interest_rate`; существующие записи с ненулевым регулярным платежом автоматически помечаются как кредитные продукты.
- Добавлены/обновлены тесты доменной модели, аналитики и Supabase persistence.
- Workflow тестирования дополнен тестом Financial Burden Domain.

## Архитектурное решение

Процентная ставка хранится как числовое значение в процентах годовых. Расчёт процентов и будущий механизм расчёта сложного процента на этом этапе не внедряются, но модель данных уже подготовлена для следующего этапа.

## Проверка

- Выполнена статическая проверка изменённых участков через GitHub.
- Локальный запуск Node.js тестов из текущего окружения невозможен: окружение не имеет сетевого доступа к GitHub.
- Изменения переданы в GitHub Actions workflow для автоматической проверки.
