# Finance Model 3.0

**Дата:** 07.10.2026  
**Время:** 16:06:41 МСК

## Запрос

Перестроить Finance без отдельного блока «Финансовая подушка». Резерв должен задаваться внутри активов. Расширить активы для вкладов и других доходных финансовых инструментов.

## Изменено

### Finance DATA

Удалён самостоятельный блок:
- «Финансовая подушка».

Оставлены четыре направления:
1. Активы;
2. Фактически заработанно;
3. Финансовая нагрузка;
4. Обязательные траты.

### Assets

Модель актива расширена полями:
- `assetType`;
- `isReserve`;
- `incomeEnabled`;
- `annualYieldRate`;
- `compoundingFrequency`.

Поддержаны типы:
- денежные средства;
- банковский счёт;
- недвижимость;
- транспорт;
- банковский вклад;
- облигации;
- инвестиции;
- другое.

Добавлены UI-переключатели:
- «Финансовый резерв»;
- «Доходный актив».

Для доходного актива доступны:
- доходность, % годовых;
- отсутствие капитализации;
- ежемесячная капитализация;
- ежеквартальная капитализация;
- ежегодная капитализация.

Фактическая стоимость актива не увеличивается автоматически от указанной доходности. Доходность хранится как параметр будущего дохода.

### FSI

Существующая модель FSI не была переписана.

Резерв теперь передаётся в FSI как сумма активов с `isReserve = true`. История резерва также формируется из Assets snapshots.

### Persistence

Добавлена миграция:

`supabase/migrations/20261007160000_finance_assets_model_3.sql`

Она:
- добавляет новые поля в `finance_assets`;
- удаляет исторические snapshots отдельного `financial-cushion`;
- исключает `financial-cushion` из `finance_snapshots`;
- удаляет таблицу `finance_cushions`;
- обновляет атомарный RPC Assets.

### Domain / Application / Memory

Удалены самостоятельные Finance Cushion Domain и Memory-контракты.

Application, Memory, Supabase adapter и Finance Analytics переведены на четырёхблочную модель.

## Тесты

Обновлены Finance Memory, Finance Analytics и Assets Domain tests под новую модель.

Автоматический CI-результат после последних коммитов на момент записи этого Change Log ещё не подтверждён.
