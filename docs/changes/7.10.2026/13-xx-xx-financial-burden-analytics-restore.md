# Восстановление аналитики кредитных обязательств

Дата: 07.10.2026

## Изменения

1. `source/application/finance/finance.js`
   - Добавлен fallback для аналитики финансовой нагрузки.
   - Если актуальная коллекция временно возвращает пустой список, аналитика использует последнюю сохранённую snapshot-версию этой коллекции.
   - Общая сумма и строки теперь не теряют связь при расхождении live-cache и snapshot.

2. `source/infrastructure/supabase/finance.memory.supabase.js`
   - Исправлена нормализация поля `interest_rate` → `interestRate`.
   - Параметр процентной ставки теперь корректно возвращается в application/domain слой после загрузки из Supabase.

## Причина

После добавления кредитных продуктов общая сумма финансовой нагрузки продолжала отображаться через аналитический metric, тогда как список строк мог быть пустым из live-коллекции. Это приводило к экрану с одной общей суммой без состава долга.

## Результат

- Состав кредитных продуктов и долгов восстанавливается из последнего валидного snapshot при пустом live-списке.
- Процентная ставка кредитного продукта корректно доступна аналитическому движку.
- FSI и расчёт общей финансовой нагрузки не изменялись.
