# FSI 3.1 — методологическое обновление

**Дата:** 07.10.2026 15:33:12

## Пользовательский запрос

Реализовать согласованную FSI 3.1:
- не вычитать финансовую подушку из ликвидных активов при расчёте LR;
- использовать защищённое геометрическое агрегирование с floor 0.05;
- отображать пользовательский FSI по шкале 0–1000 вместо 0–100.

- `source/index/finance/finance.index.js` — Version 3.0 → 3.1

## Изменения

1. LR теперь рассчитывается на основе всей ликвидной позиции:
   `LR = Liquid Assets / Mandatory Outflow`.
2. ER продолжает отдельно измерять покрытие обязательного оттока финансовой подушкой.
3. Перед геометрической агрегацией каждый компонент ограничивается снизу `0.05`.
4. Risk gates сохранены без изменения.
5. Внутренний FSI остаётся в диапазоне 0–100.
6. UI отображает значение как `FSI × 10 / 1000`.
7. Методология и CURRENT-документация синхронизированы с FSI 3.1.

## Архитектурные решения

- Веса компонентов не изменялись: CF 25%, LR 20%, ER 15%, DS 20%, NFP 10%, FT 10%.
- Геометрическое агрегирование сохранено.
- Floor 0.05 выбран как компромисс между критическим штрафом и требованием сбалансированной системы.
- Риск-гейты остаются отдельным механизмом ограничения критических состояний.

## Итог

FSI 3.1 реализован в расчётном контуре и UI. Методология и проектная документация обновлены.
