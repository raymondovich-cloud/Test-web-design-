# Admin Bot 2.2 — Security

Дата: 07.10.2026

## Изменения

- Реализован раздел «🔐 Безопасность».
- Добавлена сводка security events за 24 часа.
- Добавлен счётчик неудачных авторизаций за 24 часа.
- Добавлен счётчик событий namespace `security.*`.
- Добавлен просмотр последних security events с пагинацией.
- Добавлен просмотр деталей отдельного события.
- Добавлена фильтрация событий по `event_type` через команду `/security <event_type>`.
- Добавлена безопасная обработка metadata: в Admin Bot выводится только разрешённое поле `source`; чувствительные поля не отображаются.
- Уровень severity не выводится, поскольку соответствующего поля нет в текущей схеме `private.security_events`.
- Доступ к security events выполняется через административный service-role client и private schema.
- Существующие административные проверки Telegram не изменены.

## Проверка структуры

Таблица `private.security_events` проверена. Текущие поля:

- id
- user_id
- event_type
- occurred_at
- session_id
- metadata
- created_at

Существующий RPC `public.lifegame_admin_monitoring_24h()` используется для агрегированной сводки.
