# Изменение — архитектурное разделение FSI 4.1 и Adaptive Diagnosis

**Дата:** 07.10.2026  
**Время (МСК):** 17:00+

## Изменённые файлы

- `source/index/finance/finance.index.js` — FSI 4.1 оставлен только математическим расчётом; удалён экспорт механизма диагностики.
- `source/application/finance/finance.diagnosis.js` — диагностика переведена на получение весов непосредственно из результата FSI через `methodology.weights`; собственная копия весов удалена.
- `source/application/finance/finance.js` — остаётся оркестратором: получает текущий/исторический FSI и передаёт результаты в отдельный diagnosis-сервис.

## Что реализовано

- Формула FSI 4.1 не содержит механики текстового объяснения.
- `finance.diagnosis.js` не содержит собственной математической копии весов FSI.
- Вес компонента для анализа динамики берётся из результата самой формулы.
- Diagnosis интерпретирует математический результат, но не рассчитывает FSI заново.
- `finance.js` связывает расчёт FSI и диагностику, не поглощая логику диагностики внутрь себя.

## Архитектура

```
finance.index.js
      ↓
   FSI 4.1
      ↓
  FSI result
      ↓
finance.js
      ↓
finance.diagnosis.js
      ↓
adaptive diagnosis
      ↓
presentation/finance.js
```

Таким образом, математическая модель, интерпретация и отображение остаются отдельными ответственностями.

## Статус

Архитектурное разделение реализовано. Требуется финальная проверка сборки и пользовательский тест на реальных исторических данных Finance.
