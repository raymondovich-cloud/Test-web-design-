# Assets UX 1.0 — Progressive Disclosure

**Дата:** 07.10.2026  
**Время:** текущая сессия

## Запрос

Упростить перегруженный интерфейс блока «Активы», не дробя Finance на новые блоки и не удаляя функциональность финансовой модели.

## Изменено

### Создание актива

Базовый сценарий теперь показывает только:
- название актива;
- сумму.

Расширенные параметры перенесены в сворачиваемый блок:
- тип актива;
- ликвидность;
- финансовый резерв;
- доходный актив;
- доходность;
- капитализация.

Для банковского вклада и облигаций существующая логика доходного актива сохраняется.

### Редактирование актива

Расширенные параметры также скрыты до явного раскрытия пользователем. Данные и механика сохранены.

### Design System

Добавлен единый стиль progressive disclosure для финансовых параметров с сохранением premium black/orange визуального языка.

## Архитектурные ограничения

Не изменялись:
- Finance DATA — четыре блока;
- модель Assets;
- assetType;
- isReserve;
- incomeEnabled;
- annualYieldRate;
- compoundingFrequency;
- liquidity;
- аналитика;
- FSI;
- будущий механизм сложного процента.

## UX Design Correction

Уточнён визуальный стиль progressive disclosure:
- убрана отдельная декоративная рамка и самостоятельный градиент;
- компонент переведён на стандартные design-system tokens;
- оставлены только тонкие разделители, совпадающие с общим языком интерфейса;
- из строки «Дополнительные параметры» убрано перечисление внутренних параметров;
- trigger теперь содержит только название и системный chevron.
