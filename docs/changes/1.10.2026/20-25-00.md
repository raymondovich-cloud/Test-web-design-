# Изменение — 01.10.2026

## Liquid Funds — UX корректировка

### Согласовано

Периоды «Неделя / Месяц / Год» не должны находиться непосредственно в основном блоке «Ликвидные средства».

В основном блоке отображаются:

- текущее состояние;
- общая сумма;
- отдельные строки ликвидных средств;
- кнопка «Статистика».

По нажатию «Статистика» раскрывается внутренний блок статистики, содержащий:

- Неделя;
- Месяц;
- Год;
- сумму состояния на выбранном временном срезе;
- состав ликвидных средств на этом срезе.

### Изменено

- `source/presentation/finance/finance.js` → Version 1.5
- `source/design/patterns/statistics.css` → Version 1.3

### Архитектура

Механизм исторических снимков и правило временных срезов не изменены.

«Неделя / Месяц / Год» по-прежнему означают состояние системы на соответствующем временном срезе, а не сумму операций за период.
