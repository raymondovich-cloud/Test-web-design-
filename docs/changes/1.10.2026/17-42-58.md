Добавить возможность добавлять и удалять строки в подблоках Finance, включая ликвидные средства, фактически заработанное, финансовую нагрузку, обязательные траты и финансовую подушку. Удаление должно работать свайпом влево по принципу iOS.

## Что изменено

- В каждом Finance-подблоке добавлено собственное состояние записей.
- Реализованы операции добавления, получения списка и удаления записей.
- Добавлена Application-граница, которая координирует операции Finance между Presentation и Domain.
- В каждом открытом подблоке доступно добавление записи с названием и суммой.
- Реализован свайп строки влево с раскрытием действия «Удалить».
- Добавлено явное удаление через кнопку после свайпа.
- Добавлена возможность закрыть раскрытое действие повторным нажатием на строку.
- После добавления или удаления сохраняется открытый Finance-подблок.
- Добавлены общие Design System-стили для input и button.
- Стили свайпа и Finance-строк размещены в `list.css`.

## Причина изменения

Пользователь должен иметь возможность управлять отдельными финансовыми записями непосредственно внутри соответствующих Finance-подблоков, сохраняя единый премиальный интерфейс и iOS-подобную модель взаимодействия.

## Архитектурные решения

- Domain хранит только собственное состояние и бизнес-валидацию записей.
- Domain не обращается к Memory, Infrastructure, DOM или Design System.
- Presentation не обращается напрямую к Domain: операции проходят через `source/application/finance/finance.js`.
- Design System содержит только визуальные правила и не содержит Finance-бизнес-логику.
- `web.js`, `index.html` и Navigation не изменялись.

## Ограничение текущей реализации

Записи пока существуют только в состоянии текущего экземпляра приложения и не сохраняются между перезагрузками страницы. Постоянное хранение должно быть добавлено отдельно через предусмотренную архитектурную границу Memory/Infrastructure, без прямого доступа Domain к хранилищу.
