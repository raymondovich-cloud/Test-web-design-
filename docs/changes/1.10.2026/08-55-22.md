## Что изменено

В Finance добавлены пять независимых подблоков в следующем порядке:

1. Ликвидные средства
2. Фактически заработанно
3. Финансовая нагрузка
4. Обязательные траты
5. Финансовая подушка

Каждый подблок имеет:

- собственный заголовок;
- номер;
- описание;
- возможность сворачивания и разворачивания;
- отдельную область содержимого;
- состояние отсутствия данных.

Первый подблок открыт по умолчанию, остальные закрыты.

## Свайп-удаление

В Design System добавлена переиспользуемая основа для свайп-удаления элементов списков в стиле мобильного интерфейса.

Механизм рассчитан на будущие реальные записи Finance и не содержит бизнес-логики хранения или удаления данных.

## Архитектура

Finance UI вынесен в:

`source/presentation/finance/finance.js`

Доменные файлы Finance не изменялись.

Presentation не получает прямого доступа к Memory или Infrastructure.

Design System расширена универсальными стилями аккордеонов и списков без создания отдельного `finance.css`.
