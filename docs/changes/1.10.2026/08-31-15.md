# Изменение: обновление правил Agent

Дата: 1 октября 2026 года
Время создания: 08-31-15 MSK (UTC+03:00)

## Пользовательский запрос

Зафиксировать согласованные по итогам разбора конфликтов правила в `docs/agent.md` и удалить пункт о направлении зависимостей.

## Изменённые файлы

- `docs/agent.md`

Версия до изменения: 1.7  
Версия после изменения: 1.8

## Что изменено

1. Зафиксировано правило: Change-файлы разрешены только внутри папки закреплённого дня рабочей сессии.
2. Зафиксировано правило: день рабочей сессии остаётся неизменным при переходе через 00:00.
3. Зафиксировано правило: один пользовательский запрос, изменяющий репозиторий, создаёт один Change-файл независимо от количества изменённых файлов.
4. Зафиксировано правило: имя Change-файла содержит фактическое время его создания.
5. Зафиксировано правило: Change-файлы не версионируются.
6. Зафиксировано правило: редактирование Change-файла не создаёт новый Change, если это отдельно не заявлено.
7. Убрано рекурсивное требование создавать Change для самого Change-файла.
8. Уточнено исключение числовых директорий дат из правила строчных имён.
9. Сохранена двухэтапная модель разработки с возможностью немедленной реализации при прямом запросе пользователя без согласования.
10. `design.css` закреплён как точка входа Design System.
11. Зафиксировано, что изменение фиксированной структуры Design System возможно после отдельного согласования.
12. Удалён прежний пункт с формулой направления зависимостей `Domain → UI → Design System → Design Tokens`.

## Архитектурные решения

Направления зависимостей между блоками проекта в текущей версии `agent.md` не фиксируются. Они будут определены позднее отдельным разделом с описанием зависимостей каждого блока, источников данных и допустимых направлений взаимодействия.

## Итоговый статус

Изменения согласованных правил внесены в `docs/agent.md`. Документ обновлён до версии 1.8.
