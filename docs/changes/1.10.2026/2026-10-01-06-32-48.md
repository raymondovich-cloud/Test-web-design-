# Изменение: исправление входной страницы GitHub Pages

**Версия:** 1.0  
**Дата и время:** 01.10.2026, 06:32:48 (MSK, UTC+03:00)

## Что изменено

Добавлен корневой файл:

`index.html`

Файл является технической точкой перенаправления и открывает:

`platforms/web/index.html`

## Причина

Корневой адрес GitHub Pages продолжал открывать README.md. Это означало, что текущая конфигурация публикации могла использовать корень репозитория как источник сайта.

Корневой `index.html` устраняет зависимость от поведения GitHub Pages при выборе стартового документа и явно направляет пользователя в Web-приложение LifeGame.

## Архитектурное решение

Основной Web entry point проекта остается:

`platforms/web/index.html`

Корневой `index.html` не содержит бизнес-логики, UI-логики или функциональности приложения. Он выполняет только техническую маршрутизацию входа.

## Статус

Исправление внесено в ветку `main`.

После публикации нового коммита корневой адрес должен открывать Web-приложение LifeGame вместо README.md.
