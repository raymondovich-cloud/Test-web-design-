# Change Log — 01.10.2026

## Изменение
Finance: при первоначальном запуске все пять подблоков теперь свернуты.

## Причина
Ранее renderFinance() по умолчанию открывал "liquid-funds", из-за чего «Ликвидные средства» отображались раскрытыми сразу после открытия Finance.

## Решение
В source/presentation/finance/finance.js значение openSubblockId по умолчанию изменено с "liquid-funds" на null.

## Поведение
- При первом открытии Finance все подблоки свернуты.
- Пользователь самостоятельно открывает нужный подблок нажатием.
- При добавлении и удалении записи существующая логика открытия выбранного подблока сохраняется.

## Архитектура
Изменен только Presentation Layer. Domain и Application не затрагивались.
