## Что изменено

GitHub Pages переведён на публикацию содержимого каталога `platforms/web`.

Теперь артефакт GitHub Pages формируется из:

`platforms/web`

Поэтому файл:

`platforms/web/index.html`

становится входной HTML-страницей опубликованного Web-приложения.

Также исправлены относительные пути в `index.html`:

- Design System подключается из `../../source/design/design.css`.
- Web Entry Script подключается из `./web.js`.

## Архитектурное решение

Каталог `platforms/web` является Web application entry point.

Структура разделяет:

- `source/` — исходный код системы, включая Design System, Core и Domain;
- `platforms/web/` — Web-платформу и её точку входа;
- `.github/workflows/` — автоматизацию публикации.

README.md больше не используется как источник опубликованной Web-страницы.

## Причина

Необходимо, чтобы публичный адрес:

`https://raymondovich-cloud.github.io/LifeGame/`

открывал Web-приложение LifeGame, а не содержимое репозитория или README.md.

## Итоговый статус

Настройка GitHub Pages для публикации `platforms/web` выполнена в репозитории. После выполнения workflow публикация должна использовать `platforms/web/index.html` как стартовую страницу.
