# Изменение — 01.10.2026 20:13:37 MSK (UTC+03:00)

## Пользовательский запрос

Реализовать блок «Ликвидные средства» так, чтобы отображалась общая сумма добавленных сбережений и была возможность просматривать статистику за период.

## Изменённые файлы

- `source/domain/finance/liquid.funds/liquid.funds.js`: 1.1 → 1.2
- `source/application/finance/finance.js`: 1.0 → 1.1
- `source/presentation/finance/finance.js`: 1.3 → 1.4
- `platforms/web/web.js`: 1.3 → 1.4
- `source/design/patterns/statistics.css`: 1.1 → 1.2
- `source/core/events/event.bus.js`: создан, 1.0
- `source/memory/finance/liquid.funds.memory.js`: создан, 1.0

## Что изменено

- В Domain Liquid Funds добавлен расчёт текущей общей суммы всех записей.
- После изменения состояния Liquid Funds Domain публикует нейтральное Domain Event.
- Добавлен Core Event Bus для передачи событий без прямой зависимости Domain от Memory.
- Добавлена Memory-структура для хранения снимков состояния Liquid Funds.
- Web composition root связывает Domain Event с сохранением снимка в Memory.
- Application получил отдельный сценарий получения текущей общей суммы и статистики Liquid Funds.
- В Presentation для Liquid Funds добавлена верхняя строка с текущей общей суммой.
- Добавлен переключатель периодов «Неделя / Месяц / Год».
- Статистика основана на снимке состояния, а не на суммировании операций за период.
- Существующие отдельные строки Liquid Funds и удаление свайпом сохранены.
- Использована существующая Design System без создания отдельного `finance.css`.

## Архитектурные решения

- Зафиксировано правило: «Неделя / Месяц / Год» для stateful-сущностей означает временной срез состояния, а не сумму операций за период.
- Domain не обращается напрямую к Memory.
- Presentation не обращается напрямую к Domain или Memory.
- Историческое состояние передаётся через Core Event Bus и сохраняется на границе Web composition root.
- `navigation.js` и `app.js` не изменялись.

## Ограничение текущей реализации

Memory на этом этапе хранит снимки в памяти текущего экземпляра приложения. Постоянное, защищённое и зашифрованное хранение через Infrastructure будет реализовано отдельным архитектурным этапом и не смешивается с текущей бизнес-логикой Liquid Funds.

## Итоговый статус

Реализация Liquid Funds с текущей общей суммой и базовой статистикой по временным срезам выполнена.
