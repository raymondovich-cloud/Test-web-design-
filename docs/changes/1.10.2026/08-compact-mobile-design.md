# LifeGame — Session Change Log

**Дата:** 01.10.2026  
**Сессия:** Компактный mobile-first дизайн

## Что изменили

Полностью уплотнён общий визуальный слой с приоритетом мобильного использования. Ориентир — iPhone 17: 6,3-дюймовый дисплей, 71,5 мм шириной и 149,6 мм высотой корпуса по официальным спецификациям Apple.

### Основные изменения

- Сокращены глобальные вертикальные отступы.
- Уменьшен section-gap.
- Уменьшен component-gap.
- Уменьшены внутренние отступы Finance-подблоков.
- Подблоки стали ниже и визуально плотнее.
- Уменьшены размеры индексов и кнопок раскрытия.
- Описание подблоков теперь занимает одну компактную строку.
- Уменьшена высота пустого состояния.
- Сокращены отступы верхнего блока LIFE MODULE.
- Уменьшены размеры заголовка и вторичного текста.
- Сокращено расстояние до нижней навигации.
- Уменьшена высота элементов нижней навигации.
- Footer также сделан компактнее.
- Добавлена отдельная mobile-настройка для экранов до 480px.

## Изменённые файлы

- source/design/tokens/spacing.css — Version 1.2
- source/design/components/accordion.css — Version 1.2
- source/design/components/list.css — Version 1.2
- source/design/components/navigation.css — Version 1.4
- source/design/foundation/layout.css — Version 1.4

## Архитектура

Изменения находятся только в Design System / presentation styling.

Domain, Application, Memory и Infrastructure не изменялись.
Бизнес-логика и зависимости архитектурных слоёв не затронуты.

## Цель

На мобильном экране пользователь должен видеть больше полезной информации одновременно, при этом интерфейс должен сохранять премиальный визуальный ритм, читаемость и комфорт взаимодействия.
