# Исправление стартового модуля LifeGame

Дата и время создания: 01.10.2026 19:47:12 MSK (UTC+03:00)

## Пользовательский запрос

При открытии сайта LifeGame по умолчанию открывался Module 03 (Development). Требуется, чтобы по умолчанию открывался Module 01 (Finance).

## Изменённые файлы

- `source/application/navigation/navigation.js`: 1.2 → 1.3
- `platforms/web/web.js`: 1.2 → 1.3
- Создан Change Log: `docs/changes/1.10.2026/19-47-12.md`

## Что изменено

- В Navigation изменён идентификатор модуля по умолчанию с `development` на `finance`.
- В Web entrypoint изменён fallback стартового модуля с `development` на `finance`.
- Если URL уже содержит hash конкретного модуля, он продолжает использоваться.
- Изменение не затрагивает бизнес-логику Finance и остальные домены.

## Причина изменения

Module 01 Finance должен быть первым экраном LifeGame при обычном открытии сайта без указанного модуля.

## Архитектурное решение

Стартовый модуль является ответственностью Application Navigation и Web entrypoint, поэтому изменение выполнено в этих слоях без переноса логики в Domain или Design System.

## Итоговый статус

Реализовано. Изменения зафиксированы в Git.
