# Изменение LifeGame — 1.10.2026

## Добавлен модуль Profile

В LifeGame добавлен четвёртый основной модуль **Profile / Профиль**.

### Изменения

- Profile получил номер **04**.
- Profile размещён последним блоком нижней навигации, после Development.
- Нижняя навигация изменена с трёх на четыре равных блока.
- Добавлен маршрут `#profile`.
- Application Navigation теперь знает модуль Profile и отображает для него:
  - номер 04;
  - название Profile;
  - локальное название Профиль;
  - статус подключённого модуля;
  - активное состояние навигации.

### Архитектура

- Используется существующая папка `source/domain/profile`.
- Бизнес-логика Profile в рамках этого изменения не добавляется.
- Navigation остаётся ответственным только за навигацию и состояние выбранного модуля.
- Domain, Application и Design остаются разделёнными.

## Итоговая структура модулей

02 — Health / Здоровье  
03 — Development / Развитие  
04 — Profile / Профиль
