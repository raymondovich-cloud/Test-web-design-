# Эксперимент композиции Finance

Дата: 06.10.2026

## Изменено

Finance полностью переведён из композиции «набор одинаковых блоков» в композицию финансового рабочего пространства.

Новая иерархия:

1. **FINANCIAL HEALTH** — главный показатель состояния.
2. **CAPITAL** — общий капитал и разделение на ликвидные/неликвидные активы.
3. **FINANCIAL STRUCTURE** — единая структура из пяти направлений:
   - Capital / Активы
   - Income / Фактически заработано
   - Burden / Финансовая нагрузка
   - Expenses / Обязательные траты
   - Reserve / Финансовая подушка
4. Детализация открывается непосредственно под выбранной строкой структуры, а не отдельной карточкой.

Убрана визуальная модель пяти равноправных карточек/аккордеонов.

## UX

- По умолчанию детали закрыты.
- Активируется только выбранное направление.
- Сохранены добавление, редактирование долгим нажатием, swipe-to-delete и pin-механика.
- Сохранена аналитика активов.
- FSI-диагностика доступна из верхнего блока и не перегружает основной экран.
- Domain и Memory не изменялись.
