# LifeGame — Finance/Data: гибрид с восстановленным DATA UI

**Дата:** 06.10.2026  
**Время фиксации:** 06.10.2026, 03:28:32 MSK

## Решение

Реализован утверждённый гибрид:

1. Основной экран **Finance** сохраняет современную структуру Life OS:
   - FINANCIAL HEALTH;
   - CAPITAL;
   - DATA;
   - общая стоимость активов;
   - ликвидные и неликвидные активы.
2. После **DATA → «Открыть →»** пользователь попадает на отдельный экран DATA.
3. Внутри DATA восстановлена карточная поверхность, существовавшая до эксперимента.
4. В DATA возвращены **6 финансовых блоков 01–06**:
   - 01 — Активы;
   - 02 — Фактически заработанно;
   - 03 — Финансовая нагрузка;
   - 04 — Обязательные траты;
   - 05 — Финансовая подушка;
   - 06 — Индекс финансовой стабильности.
5. Карточки снова имеют рамку, градиентную поверхность, скругление и визуальное разделение.
6. Существующие добавление, редактирование, pinning и swipe-delete сохранены.
7. Основной Finance и финансовые данные не объединяются в один экран.
