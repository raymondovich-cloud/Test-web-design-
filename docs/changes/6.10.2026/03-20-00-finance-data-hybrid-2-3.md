# LifeGame — реализация гибрида DATA №2 + №3

**Дата:** 06.10.2026  
**Время:** 03:19 MSK

## Изменено

Реализован утверждённый гибрид концепций **Financial Systems №2 + Financial Command Center №3** внутри отдельного экрана DATA.

### DATA

- DATA остаётся отдельным экраном после нажатия «Открыть →».
- Заголовок описывает управление финансовой системой, а не отдельный CRUD-блок.
- Вместо прежнего «FINANCIAL STRUCTURE» введён уровень **FINANCIAL SYSTEMS**.
- Добавлена сводка: количество систем и общее количество записей.
- Пять финансовых направлений представлены как пять систем:
  - CAPITAL
  - INCOME
  - BURDEN
  - EXPENSES
  - RESERVE
- Сумма является главным визуальным объектом строки.
- Количество записей является вторичным показателем.
- Раскрытие системы происходит непосредственно под её строкой.

### Раскрытая система

- Добавлена крупная итоговая сумма.
- Добавлено смысловое название суммы:
  - для BURDEN — «Общий долг»;
  - для остальных систем — «Итого».
- Количество записей вынесено в отдельный вторичный показатель.
- Для CAPITAL добавлена разбивка на ликвидные и неликвидные активы.
- Для BURDEN добавлена сумма ежемесячных платежей.
- Существующие записи, добавление, редактирование, pinning и swipe-delete сохранены.

## Архитектурные ограничения

- модели хранения финансовых данных;
- существующая логика CRUD.

Изменения ограничены Presentation и Design System.
