# Сводка сессии — CAPITAL compact analytics

Дата и время: 06.10.2026 04:48:09 (Москва)

## Изменено
- Блок CAPITAL перестроен: пять финансовых показателей теперь находятся в одной компактной строке.
- Убрана визуальная модель отдельных строк внутри CAPITAL.

- Для диаграммы используются фактические процентные изменения из Finance Analytics; при отсутствии сопоставимой базы показывается «—».
- Изменения внесены только в Presentation и Design System:
  - `source/presentation/finance/finance.js` — Version 4.15.
  - `source/design/patterns/finance.css` — Version 2.0.
- Пользовательские финансовые данные и Domain не изменялись.

## Одобрено
- Компактная строка показателей вместо дополнительного dashboard.
- Диаграмма непосредственно под строкой.
- CAPITAL остаётся аналитическим read-model поверх Finance Memory / Finance Analytics.
