# Telegram: уведомления о новых регистрациях

- Дата: 06.10.2026
- Время: 23:39:00
- Часовой пояс: MSK (UTC+03:00)
- Пользовательский запрос: исправить цепочку регистрации, чтобы после регистрации нового пользователя администратор получал уведомление в Telegram.
- Изменённые файлы:
  - supabase/functions/telegram-admin/index.ts — Version 1.6 → 1.7
  - supabase/migrations/20261006233900_telegram_registration_notifications.sql — новый файл, Version 1.0
- Изменение:
  - добавлен Database Trigger на INSERT в public.profiles;
  - подключён pg_net для асинхронного HTTP-вызова;
  - секрет внутреннего webhook хранится в Supabase Vault;
  - telegram-admin получает секрет из защищённого RPC;
  - сохранена существующая Telegram webhook-логика;
  - Edge Function развёрнута как version 26.
- Причина: до изменения регистрация создавала профиль и security event, но не запускала telegram-admin.
- Архитектурное решение: уведомление запускается на стороне Supabase/Postgres, без зависимости от VPS или клиентского UI.
- Проверка:
  - pg_net установлен;
  - ровно один trigger profiles_notify_telegram_admin существует;
  - секрет Vault существует и имеет длину 64 символа;
  - service_role имеет EXECUTE только на защищённом RPC;
  - telegram-admin активна, version 26.
- Ограничение проверки: фактическая отправка Telegram на новой регистрации не выполнялась искусственным тестовым пользователем, чтобы не создавать лишнего пользователя и не отправлять ложное уведомление.
- Итоговый статус: IMPLEMENTED; требуется один реальный тест регистрации для подтверждения полного end-to-end цикла.
