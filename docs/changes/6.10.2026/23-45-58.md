  - количество пользователей;

  - существующие уведомления о регистрации сохранены.
- Безопасность:
  - команды доступны только TELEGRAM_ADMIN_CHAT_ID;
  - внутренние webhook-вызовы проверяются существующим защищённым секретом;
  - в Telegram для security event передаётся только тип события, укороченный user id и время;
  - содержимое metadata security event не отправляется.
- Архитектурное решение:
  - Admin Bot остаётся Edge Function;
  - БД инициирует security-event уведомления через pg_net;
  - решение не зависит от VPS;
  - пользовательские данные не становятся доступными через Telegram-команды.
- Проверка:

  - реальное подтверждение команд /status и security-event уведомления требует отдельного ручного теста через Telegram.
