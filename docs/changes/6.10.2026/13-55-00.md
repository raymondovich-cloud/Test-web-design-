# Изменение: удалён дубль индекса финансовой стабильности из управления финансовыми данными

**Дата:** 06.10.2026  
**Время:** 13:55:00 (МСК)  
**Запрос:** убрать блок «Индекс финансовой стабильности» из раздела «Управление финансовыми данными», сохранив сам индекс и его механику.

## Изменено
- Удалён только элемент `financial-stability-index` из списка блоков управления финансовыми данными.
- Раздел теперь содержит 5 блоков: «Активы», «Фактически заработанно», «Финансовая нагрузка», «Обязательные траты», «Финансовая подушка».
- Расчёт индекса, его отображение на основном экране «Финансы» и связанная механика не изменялись.
- `finance.js` обновлён до Version 4.27.
