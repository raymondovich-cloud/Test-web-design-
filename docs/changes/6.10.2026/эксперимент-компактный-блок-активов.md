# Эксперимент: компактный блок активов

**Дата и время:** 6.10.2026, 15:36:00  
**Часовой пояс:** MSK (UTC+03:00)  
**Статус:** EXPERIMENT

## Запрос

Сделать блок «Активы» более компактным, уменьшив внутренние отступы на 40%.

## Реализация

Изменение выполнено только для `data-subblock="assets"`.

Используется коэффициент `0.6` от текущих Design System spacing tokens.

Уменьшены:
- внутренние отступы заголовка блока;
- отступы контента;
- внутренние отступы summary;
- отступы общей суммы и даты;
- внутренние вертикальные отступы финансовых строк;
- отступ перед формой добавления;
- отступ между списком данных и формой.

Не уменьшены:
- расстояние между строками;
- расстояние между кнопками;
- высота кнопок;
- глобальные spacing tokens;
- другие финансовые блоки.

## Изменённый файл

- `source/design/patterns/finance.css`: Version 2.7 → Version 2.8

## Архитектура

Изменение выполнено исключительно на уровне Design System / Finance pattern. Бизнес-логика, Domain, Application, Memory и Presentation JavaScript не изменялись.

## Следующая проверка

Визуально оценить эксперимент на мобильном экране и определить, является ли компактность оптимальной. При необходимости вернуть, ослабить или закрепить значение 40%.
