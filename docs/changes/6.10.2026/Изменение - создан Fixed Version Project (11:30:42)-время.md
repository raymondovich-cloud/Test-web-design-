## Что изменено

Создан отдельный документ Fixed Version Project.

В него вынесена только явно зафиксированная базовая система LifeGame, определённая в `docs/agent.md` на 06.10.2026.

Документ явно отделён от:
- CURRENT состояния проекта;
- Change Log;
- рабочих сессий;
- планов;
- исторических документов.

## Причина изменения

В `docs/agent.md` уже была определена роль Fixed Version Project, но отдельного документа с этой ролью в репозитории не было.

`docs/project-state.md` не используется для этой цели, поскольку содержит смешение точки остановки, текущего состояния и исторически устаревших сведений и требует отдельного аудита.

## Архитектурное решение

Fixed Version Project имеет статус **BASELINE** и фиксирует только явно утверждённую основу.

Он не объявляет описанные пункты автоматически CURRENT и не заменяет проверку фактического кода и тестов.
