# Исправление раскрытия финансовой категории

**Дата:** 06.10.2026  
**Время:** после фикса DATA screen  
**Раздел:** Finance → DATA → Financial Structure

## Изменено

Исправлена композиция раскрытия финансовых категорий.

Ранее `createStructure()` сначала выводил все строки категорий, а подробный блок выбранной категории добавлял после всего списка. Из-за этого при выборе «Активы» содержимое отображалось внизу экрана.

Теперь подробный блок активной категории добавляется непосредственно после соответствующей строки внутри `FINANCIAL STRUCTURE`.

Пример:

```text
CAPITAL
Активы
...

АКТИВЫ
...
Добавить

INCOME
Фактически заработано
...
```

Изменён файл:

- `source/presentation/finance/finance.js` — Version 4.5

## Архитектура

Изменение ограничено presentation-слоем. Domain, application и memory не изменялись.

## Проверка

Автоматические тесты не запускались.

## План

Проверить визуально на GitHub Pages:

1. Finance отображается.
2. DATA открывается отдельным экраном.
3. «Активы» раскрываются непосредственно под строкой «Активы».
4. Остальные категории остаются ниже раскрытого блока.
5. Добавление, редактирование и удаление работают внутри выбранной категории.
6. `← Finance` возвращает на основной Finance screen.
