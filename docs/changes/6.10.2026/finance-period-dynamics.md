# Динамика финансовых показателей

Дата: 06.10.2026
Изменение: добавлена историческая аналитика пяти финансовых показателей за месяц.

## Изменено

- Finance Memory получил snapshots для всех финансовых коллекций.
- Finance Application стал записывать историю через Memory.
- Добавлен finance.analytics.js.
- В Capital отображается динамика пяти показателей.
- Проценты рассчитываются относительно предыдущего сопоставимого месячного состояния.
- При нулевой или отсутствующей базе отображается —, без искусственного процента.
- Для Supabase добавлена persistent-таблица finance_snapshots с RLS.
- Добавлены тесты расчёта динамики.
- GitHub Actions расширен новым finance analytics test.

## Архитектурная граница

История не хранится в Domain. Domain продолжает формировать только финансовые факты; snapshots находятся в Memory/Infrastructure, расчёт выполняется Application, отображение — Presentation.

## Верификация

Supabase: таблица public.finance_snapshots создана и проверена SQL-запросом. Security advisor не выявил проблем у новой таблицы; существующие предупреждения относятся к другим объектам проекта.
