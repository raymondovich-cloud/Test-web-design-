## Что изменено

### Нормативные правила

`docs/agent.md` приведён к роли нормативного документа и больше не содержит BASELINE конкретного этапа проекта.

Зафиксировано:

- `index/` как отдельная архитектурная подсистема расчётных показателей;
- FSI 2.1 как официальная терминология финансового индекса;
- отдельные роли Agent Rules, Fixed Version Project и Current state;
- статусы IMPLEMENTED, PLANNED и FUTURE;
- требования к документационному аудиту.

### Fixed Version Project

`docs/fixed-version-project.md` расширен до полного BASELINE и включает согласованную архитектурную подсистему `index/`, Finance-модель, Assets, Financial burden, FSI 2.1, Design System и правила фиксации.

### Current state

`docs/project-state.md` обновлён как CURRENT-документ.

В нём зафиксированы только подтверждённые актуальные сведения, включая текущий Web Auth/Profile flow, Identity migrations, Finance DATA, Assets, Financial burden и FSI 2.1.

### Identity UI

`docs/architecture/IDENTITY_UI_BOUNDARY.md` переведён в фактическое CURRENT-состояние.

Отдельно разделены IMPLEMENTED, PLANNED и FUTURE. Текущий modal Registration/Login flow описан как фактическая реализация, а не как незавершённая целевая архитектура.

### Identity Database

`docs/security/IDENTITY_DATABASE_SCHEMA.md` переведён из проектируемого состояния в CURRENT.

Документ сверён с миграциями `0001`–`0004` и отдельно разделяет IMPLEMENTED, PLANNED и FUTURE.

## Архитектурные решения

1. Официальное название индекса — FSI 2.1.
2. `index/` является отдельной архитектурной подсистемой.
3. `docs/agent.md` содержит только нормативные правила.
4. `docs/fixed-version-project.md` содержит полный BASELINE.
5. `docs/project-state.md` содержит CURRENT-состояние.
6. Security-документы `SECURITY_ARCHITECTURE.md` и `THREAT_MODEL.md` в рамках этой задачи не изменялись.
