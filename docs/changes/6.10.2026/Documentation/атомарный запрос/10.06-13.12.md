# Change: атомарный запрос — один commit и один Change-файл

- Дата: 06.10.2026
- Время: 13:12
- Часовой пояс: MSK (UTC+03:00)
- Пользовательский запрос: зафиксировать новое правило атомарности изменений — один запрос, один commit и один Change-файл.
- Изменённые файлы:
  - `docs/agent.md` — Version 2.3 → Version 2.4
  - `docs/changes/6.10.2026/Documentation/атомарный запрос/10.06-13.12.md`
- Описание изменения: в нормативные правила добавлено требование, что каждый пользовательский запрос, изменяющий репозиторий, является одной атомарной операцией. Все изменения этого запроса и его единственный Change-файл фиксируются одним Git commit. Commit и Change-файл используют общую идентичность области, сути и даты; время указывается только в имени Change-файла. Новый запрос, включая отмену или изменение результата предыдущего запроса, создаёт новую атомарную операцию.
- Причина: исключить расхождение между историей Git и Change Log и закрепить единый проверяемый жизненный цикл изменения.
- Принятое архитектурное решение: Change-файл является частью того же commit, что и изменение репозитория, и не создаёт отдельный commit.
- Итоговый статус: CURRENT
