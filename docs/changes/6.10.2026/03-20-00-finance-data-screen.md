# Изменение: DATA как отдельный экран

Дата: 6.10.2026

## Изменено

- Finance DATA больше не раскрывается ниже основного экрана Finance.
- Кнопка «Открыть →» переводит пользователя в отдельный presentation-режим DATA.
- В DATA добавлен возврат «← Finance».
- FINANCIAL STRUCTURE и CRUD финансовых записей теперь работают внутри DATA-экрана.
- После добавления и удаления записи пользователь остается в DATA.
- Верхняя одобренная часть Finance не изменена.
- Domain и Memory не изменялись.

## Техническая реализация

- source/presentation/finance/finance.js → Version 4.4.
- Добавлен renderFinanceData(...).
- renderFinance(...) снова отвечает только за основной экран Finance.
- Существующий rollback сохранен.
