# Change Log — унификация контракта key envelope

- Дата: 10.10.2026
- Время: 15:58 МСК
- Ветка: `feature/pwa-static-cache`

## Изменения

- В encryption provider contract поле `wrappedKey` заменено на нейтральное `keyEnvelope`.
- Software-only provider передаёт случайный HKDF salt как key envelope.
- KMS provider передаёт зашифрованный DEK в том же контракте.
- Supabase repository переводит общий key envelope в `payload_key_envelope` без зависимости от конкретного провайдера.
- Unit-тесты обновлены для обоих provider adapters и repository.

## Причина

Единый контракт позволяет заменить бесплатный development provider на managed-key provider без изменения бизнес-логики или схемы предметного слоя.

## Безопасность

Изменения затрагивают только имена полей инфраструктурного контракта. Ключи, secrets, cloud resources и удалённая база не изменялись.
