# Change Log — исправление контракта key envelope по результатам CI

- Дата: 10.10.2026
- Время: 16:01 МСК
- Ветка: `feature/pwa-static-cache`

## Причина

После унификации `wrappedKey` → `keyEnvelope` CI выявил несогласованные локальные имена в KMS adapter и тестовом encryption fake.

## Исправления

- Исправлены проверки размера key envelope в AWS KMS adapter для encrypt/decrypt.
- Тестовый encryption provider repository обновлён до поля `keyEnvelope` и корректного 32-байтового тестового значения.
- Production AWS KMS provider остаётся не подключённым к development entrypoint.

## Проверка

Повторный CI запускается после коммита; до его завершения тесты не считаются пройденными.
