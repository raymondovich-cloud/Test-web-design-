# Change Log — синхронизация версии миграции с Supabase

- Дата: 10.10.2026
- Время: 15:54 МСК
- Ветка: `feature/pwa-static-cache`

## Причина

Supabase записал применённую миграцию как `20261010125401_create_training_sessions`. Имя файла в репозитории синхронизировано с фактической версией, чтобы локальная история миграций не пыталась повторно создать таблицу.

## Изменения

- Переименован migration-файл в `supabase/migrations/20261010125401_create_training_sessions.sql`.
- Обновлены ссылки на миграцию в security contract.
- Комментарий поля `payload_key_version` уточнён: он описывает версию провайдера шифрования, а не только AWS KMS.

## Безопасность

Изменён только файл миграции в GitHub и документация. Повторное применение SQL не выполнялось; удалённая база не менялась этим коммитом.
