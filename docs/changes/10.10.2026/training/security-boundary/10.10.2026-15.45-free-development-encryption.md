# Change Log — бесплатное шифрование дневника тренировок

- Дата: 10.10.2026
- Время: 15:45 МСК
- Ветка: `feature/pwa-static-cache`

## Что изменено

- Добавлен software-only encryption provider на Web Crypto: HKDF-SHA-256 + AES-256-GCM.
- Edge Function entrypoint больше не требует AWS SDK, AWS credentials или AWS KMS для development path.
- Master key читается только из server-side env `TRAINING_ENCRYPTION_MASTER_KEY`; версия ключа — `TRAINING_ENCRYPTION_KEY_VERSION`.
- Унифицировано поле базы `payload_key_envelope`: для текущего development provider хранит случайный HKDF salt, для будущего managed-KMS provider сможет хранить wrapped DEK.
- Добавлены тесты уникальности salt/nonce, корректного decrypt, отказа при tampering/context mismatch и неизвестной версии ключа.
- AWS KMS adapter сохранён отдельно как возможный будущий provider, не подключён к entrypoint.

## Границы безопасности

- Бесплатный software-only provider предназначен только для development/staging. Он не обеспечивает изоляцию ключа уровня KMS и не имеет полноценной ротации/управляемого восстановления.
- Не добавлялись секреты, AWS resources, платные сервисы и remote database changes.
- Edge Function не развёрнута; миграция не применялась к удалённой базе.
- Production deployment запрещён до выбора, проверки и согласования managed key management.

## Проверки

- GitHub Actions автоматически запустится после коммита. До успешного завершения Preview CI и Database Tests изменение не считать проверенным полностью.
