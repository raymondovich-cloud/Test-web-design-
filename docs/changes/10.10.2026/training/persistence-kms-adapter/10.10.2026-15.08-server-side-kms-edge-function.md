## Реализация

- Добавлен HTTP handler для операций create/get/start/complete/revise.
- Каждый запрос требует Bearer JWT; user identity повторно проверяется через Supabase Auth. Запросы к БД выполняются user-scoped клиентом под RLS.
- Для браузерных запросов действует allowlist Origin; методы и content type ограничены; размер тела ограничен 256 KiB; ответы имеют no-store; ошибки возвращаются без внутренних сообщений.
- Edge entrypoint использует закреплённые версии Supabase JS и AWS SDK KMS. DEK получается через GenerateDataKey и восстанавливается через Decrypt с Encryption Context.
- KMS key mapping, регион и credentials читаются только из Edge Function environment secrets; секреты не добавлены в Git.
- CI расширен unit-тестами HTTP/auth/validation/error handling и CORS preflight.
