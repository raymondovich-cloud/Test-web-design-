# Change Log — Статус пользователя в настройках профиля

- **Дата:** 10.10.2026
- **Время:** 01:55:19 MSK (UTC+03:00)
- **Пользовательский запрос:** добавить в настройки профиля нередактируемую строку «Статус пользователя»; в дальнейшем отображать статус создателя, Gold Status для первых 1000 пользователей и обычный статус с отдельной подпиской.
- **Статус:** IMPLEMENTED — добавлена информационная строка с временным значением «Пользователь». Серверное назначение статусов и Gold-нумерация остаются отдельным будущим этапом.

## Изменённые файлы

- `source/presentation/profile/profile.js` — Version 1.5 → 1.6.
- `docs/changes/10.10.2026/profile/user-status/10.10-01.55.md` — создан, Version 1.0.

## Что изменено

В настройках профиля добавлена строка «Статус пользователя». Она создаётся без обработчика действия, поэтому не открывает редактирование. Строка использует существующую разметку настроек и отдельный CSS-класс `profile-settings-row--readonly`.

## Причина

Подготовить интерфейс к будущей системе пользовательских статусов, не смешивая статус аккаунта с подпиской и не создавая фиктивную серверную логику.

## Архитектурные решения

- Изменён только существующий Presentation-компонент и добавлен обязательный Change Log.
- Существующие сценарии редактирования имени и даты рождения не менялись.
- Значение «Пользователь» является временным отображением, а не подтверждённым серверным статусом.
- Статус создателя и Gold Status нельзя безопасно назначать на клиенте. Для них потребуется отдельный серверный источник истины и атомарное распределение уникальных номеров.
- Данные подписки не объединяются с пользовательским статусом.

## Проверка

- Проверено, что строка создаётся без action-callback и не получает роль кнопки.
- Проверено, что существующие строки имени, даты рождения и email сохраняются.
- Требуется подтверждение визуального результата в тестовой среде после публикации GitHub Pages.
