# Автоматическая проверка и запуск тестовой публикации

- **Дата:** 10.10.2026
- **Время:** 00:25 MSK (UTC+03:00)
- **Пользовательский запрос:** реализовать постоянный механизм проверки LifeGame в среде разработки, не затрагивая основную ветку репозитория LifeGame.
- **Изменённые файлы:**
  - `.github/workflows/preview-publish.yml` — новый файл, Version 1.0.
- **Решение:** рабочая ветка `feature/pwa-static-cache` запускает проверку обязательных web-файлов и локальных CSS-импортов, затем отправляет событие публикации в `raymondovich-cloud/Test-web`, если задан секрет `TEST_WEB_DISPATCH_TOKEN`.
- **Безопасность:** токен не хранится в коде; он читается только из GitHub Actions Secrets. Если секрет не задан, workflow выдаёт предупреждение, а Test-web использует плановый запуск как резервный механизм.
- **Границы:** основная ветка LifeGame не изменяется; workflow не выполняет merge.
- **Статус:** workflow добавлен; фактический запуск и публикация должны быть подтверждены после коммита.
