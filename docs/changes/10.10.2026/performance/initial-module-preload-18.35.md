## Изменение

Добавлены `rel="modulepreload"` для `web.runtime.js?v=20261008-2140` и `source/presentation/finance/finance.js`. Браузер получает подсказку начинать загрузку обязательных JavaScript-модулей и их статических зависимостей во время обработки HTML, не дожидаясь выполнения цепочки `web.js → web.runtime.js → Finance`.

## Причина

Статический анализ показал, что первый экран Finance ожидает динамического импорта runtime, а затем presentation-модуля Finance. Эти модули нужны для первоначального пользовательского сценария, поэтому ранняя загрузка может сократить задержку до отрисовки содержимого без изменения бизнес-логики.

## Архитектурные решения и безопасность

- Изменён только HTML entrypoint; Domain/Application/Infrastructure и сценарии авторизации не менялись.
- URL runtime preload точно совпадает с URL динамического импорта в `platforms/web/web.js`.
- Finance preload использует URL без query-параметров, соответствующий пути импорта из runtime.
- Не добавлены библиотеки и не изменена политика кэширования пользовательских данных.
- CSS и Service Worker не менялись.
