# Оптимизация проверки сессии при навигации

- Дата: 10.10.2026
- Ветка: `feature/pwa-static-cache`
- Файл: `platforms/web/web.runtime.js`, Version 5.14 → 5.15.
- Причина: обычная проверка маршрута использовала `readSessionWithHydrationRetry()`, выполняющую до четырёх последовательных чтений сессии с дополнительными задержками до 760 мс, не считая времени SDK.
- Изменение: обычная навигация теперь вызывает `application.auth.getCurrentSession()` один раз и записывает длительность проверки в существующую диагностическую трассу, если она включена.
- Сценарий после успешного входа/регистрации по-прежнему использует ограниченный retry для завершения гидратации сессии.
- Не изменялись Supabase-конфигурация, правила авторизации, пользовательские данные, UI модулей и бизнес-логика.
- Статус: изменение сохранено в тестовой ветке. Полный браузерный прогон, реальные показатели времени и CI требуют отдельной проверки.
