## Диагностика

- Проверен workflow тестовой публикации: сборка и deploy завершились успешно.
- Логи сборки подтвердили, что в публикацию попал LifeGame commit `0a519e2d65fb5931b69d06e06dc310e7ca85b808`; проблема не объясняется сборкой старой ветки.
- CSS загружается по стабильным URL без версий. Service Worker выполняет сетевой запрос, но не запрещает браузерному HTTP-кэшу вернуть ранее сохранённые ответы.
- Предыдущая правка не меняла URL CSS и повторяла уже имеющиеся ограничения ширины, поэтому визуальный эффект мог отсутствовать.

## Изменения

- Добавлена версия в URL главного файла Design System и в URL импортов двух изменяемых CSS-файлов, чтобы Safari запросил актуальные стили.
- Сетка форм и полей теперь явно использует `minmax(0, 1fr)` и `min-width: 0`, ограничивая intrinsic/min-content sizing.
- Для нативного поля даты добавлены inline-ограничения ширины и сброс системного appearance; тип `date` и логика регистрации не менялись.

## Архитектурные решения

- Бизнес-логика, данные пользователей, зависимости и архитектурные слои не затронуты.
- Рабочая ветка: `feature/pwa-static-cache`. Ветка `main` не изменялась.
