# Корректировка ширины поля даты рождения

- **Дата:** 10.10.2026
- **Время:** 16:00 MSK (UTC+03:00)
- **Пользовательский запрос:** исправить ситуацию, когда после предыдущего CSS-изменения ширина рамки поля даты рождения визуально не изменилась.
- **Статус:** IMPLEMENTED; повторная публикация и визуальная проверка Safari/iOS ожидают подтверждения.

## Изменённые файлы

1. `source/design/patterns/forms.css` — Version 1.1 → 1.2.
2. `source/design/components/input.css` — Version 1.5 → 1.6.

## Анализ причины

- Глобальный reset уже задаёт `box-sizing: border-box` для всех элементов, поэтому добавление этого свойства только в `.input-control` не меняло фактическое поведение.
- CSS формы не ограничивал минимальную ширину grid-элемента `.form-field`; нативное поле даты в Safari может влиять на intrinsic/min-content sizing контейнера.
- Последняя тестовая публикация Test-web запускалась до исправляющего коммита и поэтому не содержала его.

## Изменение

- Добавлен `min-width: 0` к `.form-field`, чтобы intrinsic-ширина вложенного контрола не расширяла grid-элемент.
- Для `.input-control[type="date"]` явно заданы `display: block`, `width: 100%`, `min-width: 0`, `max-width: 100%` и `box-sizing: border-box`.
- Нативный тип date и поведение выбора даты сохранены.

## Архитектурные решения

- Изменены только CSS-модули Design System.
- Не изменялись регистрационная логика, данные пользователя или зависимости.
- Рабочая ветка: `feature/pwa-static-cache`. `main` не изменяется.

## Проверка

- Подтверждено по коду: глобальный reset уже задаёт `box-sizing: border-box`.
