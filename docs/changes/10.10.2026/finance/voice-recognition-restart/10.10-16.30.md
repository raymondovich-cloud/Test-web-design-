# Change Log — Повторный запуск голосового распознавания в Safari

- **Дата:** 10.10.2026
- **Время:** 16:30 MSK (UTC+03:00)
- **Запрос:** пользователь сообщил, что после предыдущего исправления Safari всё ещё завершает прослушивание без текста.
- **Статус:** IMPLEMENTED IN REPOSITORY — создан отдельный экземпляр распознавания на каждый запуск; требуется CI, публикация и повторный тест на устройстве.

## Изменённые файлы
- `source/infrastructure/voice/speech-recognition.adapter.js` — Version 1.1 → 1.2.
- `docs/changes/10.10.2026/finance/voice-recognition-restart/10.10-16.30.md` — создан, Version 1.0.

## Причина
Пользователь подтвердил, что интерфейс запускает прослушивание, но браузер завершает его без результата. Это происходит до передачи текста в Application-парсер, поэтому изменение правил разбора чисел не решает симптом. WebKit имеет зарегистрированные проблемы жизненного цикла Web Speech API на отдельных версиях iOS; это возможное объяснение, но не доказательство конкретной причины на устройстве пользователя.

## Что изменено
- Адаптер создаёт новый `SpeechRecognition`/`webkitSpeechRecognition` экземпляр для каждой попытки вместо повторного использования одного экземпляра.
- Сохраняется обработка событий результата, ошибок и завершения.
- Повторный запуск блокируется, пока предыдущий экземпляр активен.
- Сообщение при завершении без результата обновлено: оно больше не предполагает, что пользователь обязательно начал говорить слишком поздно.

## Архитектура и безопасность
- Изменение изолировано в Infrastructure-адаптере браузерного API.
- Domain и Application-парсер не меняются; новые зависимости не добавлены.
- LifeGame не сохраняет аудио и не добавляет собственную отправку аудиоданных в сеть. При этом распознавание браузера может использовать системную/внешнюю службу платформы.

## Проверки и ограничения
- Требуется проверить сценарии: успешный результат, завершение без результата, ошибка распознавания и повторный запуск.
- CI и тестовая публикация должны завершиться до повторного теста на iPhone.
- Создание нового экземпляра — обходной путь для возможной проблемы повторного использования WebKit-распознавателя, а не гарантия исправления системной службы распознавания.
