# Change Log — Анимация финансового индекса

- **Дата:** 10.10.2026
- **Время:** 00:56 MSK (UTC+03:00)
- **Пользовательский запрос:** добавить премиальную анимацию счётчика финансового индекса при открытии раздела «Финансы».
- **Изменённые файлы:**
  - `source/presentation/finance/finance.js` — Version 7.12 → 7.13.
  - `source/presentation/shared/count-up.animation.js` — создан, Version 1.0.
- **Что изменено:** числовое значение FSI плавно увеличивается от нуля до рассчитанного значения по шкале 0–1000 за 1,8 секунды с постепенным замедлением в конце. После анимации отображается точное значение.
- **Архитектурные решения:** анимация находится в Presentation и вынесена в отдельный helper с одной ответственностью. Формула индекса, Application, Domain, Memory и сохранение пользовательских данных не менялись. Промежуточные значения существуют только в DOM и не сохраняются.
- **Доступность и устойчивость:** учтена настройка `prefers-reduced-motion`; значение не озвучивается на каждом кадре; при удалении элемента цикл анимации прекращается.
- **Границы:** изменение внесено только в `feature/pwa-static-cache`. `LifeGame/main` не изменяется.
- **Проверка:** перед коммитом выполнена проверка целевых фрагментов и безопасного применения патча. После push ожидается автоматический CI и публикация в Test-web; визуальная проверка выполняется отдельно в тестовом превью.
- **Статус:** IMPLEMENTED — код и Change Log подготовлены для тестовой публикации.
