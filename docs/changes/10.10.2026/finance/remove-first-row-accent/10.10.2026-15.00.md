# Удаление акцентной линии в первой строке финансовых графиков

Дата: 10.10.2026

## Причина
Первый элемент каждого графика получал класс `is-focus` из `source/presentation/finance/finance.js`. CSS-класс добавлял оранжевую вертикальную линию, дополнительный отступ и отдельный цвет подписи.

## Изменения
- Удалено автоматическое назначение `is-focus` в рендеринге графика.
- Удалено неиспользуемое CSS-правило `.finance-capital-chart-column.is-focus`.
- Обновлены версии файлов: `finance.js` — 7.35; `finance.css` — 3.10.
- Изменения выполнены только в ветке `feature/pwa-static-cache`; `main` не изменялась.

## Проверка
- Повторно загружены оба файла из тестовой ветки.
- Подтверждено отсутствие назначения `is-focus` в `finance.js` и соответствующего CSS-селектора в `finance.css`.
- Поиск `is-focus` через индекс GitHub не вернул совпадений; это дополнительная проверка, но не замена локальному прогону тестов.
- Автоматические тесты и визуальная проверка на тестовом сайте на момент записи не запускались.
