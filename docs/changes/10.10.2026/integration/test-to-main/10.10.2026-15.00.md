# Перенос тестовой версии LifeGame в основную ветку

- **Дата:** 10.10.2026
- **Статус:** подготовлен интеграционный коммит для Pull Request; основная ветка не изменена напрямую.

## Состав

- За основу взята актуальная тестовая ветка `feature/pwa-static-cache`, включая последние интерфейсные изменения, голосовой помощник, жизненный цикл обязательств, тесты и PWA preview.
- Сохранены изменения основной ветки в настройках профиля и финансовом хранилище.
- Интеграционный тест Supabase взят из `main` (Version 1.7), поскольку тестовая ветка содержала более раннюю версию с ошибкой в объявлении вспомогательной функции.
- Сохранены журналы изменений финансовых исправлений и статуса пользователя из `main`.
- Тестовая ветка и отдельный репозиторий публикации Test-web не изменяются и не удаляются.

## Архитектурные решения

- Подготовлен отдельный интеграционный коммит с родителями `main` и `feature/pwa-static-cache`.
- Все файлы тестовой ветки сохранены, кроме интеграционного теста Supabase, заменённого исправленной версией из основной ветки; журналы main добавлены без удаления новых журналов.
- Удалённые в main модули разработки не удаляются из результата: актуальная тестовая версия сохраняет их, так как это часть текущего пользовательского продукта.
- Перед окончательным слиянием необходимо дождаться CI на Pull Request и проверить статус слияния.
