# Перенос перехода анимации полос в Design System

Дата: 10.10.2026
Ветка: `feature/pwa-static-cache`

## Причина
`source/presentation/shared/bar.animation.js` задавал inline-свойство `transition`, смешивая механизм анимации с декларацией визуального поведения. Функция используется в Finance, Health и Development.

## Изменения
- В `bar.animation.js` удалено прямое назначение `element.style.transition`.
- JavaScript передаёт только динамическую длительность через CSS custom property `--bar-animation-duration`.
- CSS переходы обновлены в `finance.css` и `health.css`.
- Для `development-factor__fill` добавлено правило перехода в `development.css`.
- При включённом `prefers-reduced-motion` длительность устанавливается в `0ms`.
- Версии: `bar.animation.js` — 1.1; `finance.css` — 3.11; `health.css` — 2.1; `development.css` — 1.4.

## Проверка
- Изменения записаны только в `feature/pwa-static-cache`.
- Повторно загружены изменённые файлы и проверены версия и наличие CSS transition declarations.
- Автоматические тесты и браузерная визуальная проверка не запускались в этой сессии.
- Отдельные операции записи через GitHub API создали отдельные коммиты на каждый файл. Этап исправления оранжевой линии был предварительно зафиксирован отдельной контрольной записью.
