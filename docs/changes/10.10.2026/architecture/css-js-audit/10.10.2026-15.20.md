# Аудит CSS/JavaScript-разделения в интерфейсе

Дата: 10.10.2026
Ветка: `feature/pwa-static-cache`

## Цель
Найти в интерфейсном коде случаи, когда JavaScript содержит статические CSS-правила вместо управления состоянием или передачи динамических значений стилевой системе.

## Результаты

### 1. Исправлено в отдельном изменении
- Удалено назначение `is-focus` первому ряду графика в Finance.
- Удалено соответствующее CSS-правило с оранжевой линией и дополнительным отступом.
- Проверены текущие версии файлов: назначение класса и CSS-селектор отсутствуют.

### 2. Подтверждённый кандидат на отдельную очистку
В `source/presentation/shared/bar.animation.js` JavaScript задаёт не только динамическую ширину полосы, но и статическую функцию перехода:
`element.style.transition = "width " + duration + "ms cubic-bezier(0.22, 1, 0.36, 1)"`.

Кривая перехода относится к Design System и должна быть определена в CSS. JavaScript может передавать только динамическую длительность через CSS custom property. Это не связано с удалённой оранжевой линией и требует отдельного небольшого изменения с проверкой всех потребителей `animateBarWidth`.

### 3. Динамические значения — не считать автоматически архитектурной ошибкой
В проверенных файлах встречаются:
- ширина полосы, зависящая от рассчитанного показателя;
- CSS custom properties для смещения при свайпе;
- высота удаляемой строки, вычисленная по фактическому layout;
- размер текста суммы, адаптируемый к длине числа.

Это runtime-значения, а не полные CSS-правила. Их нельзя удалять механически; при последующей очистке следует предпочитать CSS custom properties и держать декларации/переходы в Design System.

### 4. Классы состояний
Использование `classList` для состояний вроде `is-visible`, `is-swiping`, `is-delete-ready`, `is-active` само по себе корректно: JavaScript сообщает о состоянии интерфейса, а CSS отвечает за его отображение.

## Ограничение охвата
Инструмент поиска кода GitHub индексирует ветку по умолчанию, а не гарантированно `feature/pwa-static-cache`. Поэтому результаты по поисковому индексу использовались только как вспомогательные; выводы о тестовой версии сделаны по непосредственно загруженным файлам из указанной ветки. Полный репозиторный аудит каждого файла и автоматические тесты локально не запускались в этой сессии.

## Рекомендация
Отдельным следующим изменением вынести кривую и декларацию transition из `bar.animation.js` в Design System, оставив JavaScript только вычисление и передачу динамической длительности/ширины. Не менять динамические inline-значения без проверки потребителей и визуального поведения.
