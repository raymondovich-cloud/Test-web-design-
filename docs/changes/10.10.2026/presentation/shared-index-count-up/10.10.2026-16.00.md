# Change Log — Общая анимация индексов

- **Дата:** 10.10.2026
- **Время:** 16:00 MSK (UTC+03:00)
- **Пользовательский запрос:** переиспользовать существующую механику анимации индекса в основных блоках LifeGame, чтобы не переносить её заново при разработке каждого модуля.
- **Изменённые файлы:**
  - `source/presentation/shared/count-up.animation.js` — Version 1.0 → 1.1.
  - `source/presentation/health/health.js` — Version 2.2 → 2.3.
  - `source/presentation/development/development.js` — Version 1.5 → 1.6.
- **Что изменено:** общий Presentation-helper поддерживает десятичную точность и форматирование вывода. Health Index и оба отображения Development Index используют существующий helper с длительностью 1,8 секунды и плавным замедлением. Конечные значения сохраняют исходный формат до одного знака после запятой; Development Dynamics сохраняет суффикс `/100`.
- **Архитектурные решения:** новая библиотека и зависимости не добавлялись. Анимация остаётся общей UI-механикой в `presentation/shared`; формулы индексов, Domain, Application, Memory и сохранение данных не менялись. Промежуточные числа существуют только в DOM. Учтён `prefers-reduced-motion`.
- **Profile:** визуальный индикатор профиля пока содержит статическое демонстрационное значение 760/1000 и не подключён к вычисленному Life Quality Index. Он намеренно не анимируется до подключения реального индекса, чтобы не создавать ложную динамику.
- **Границы:** изменения внесены только в `feature/pwa-static-cache`. `LifeGame/main` не изменяется.
- **Проверка:** проверены целевые участки кода и обязательные якоря изменений. После коммита ожидаются CI и публикация в Test-web; визуальная проверка анимации в Safari требует отдельного подтверждения.
- **Статус:** IMPLEMENTED — общая механика подключена к Health и Development; Profile ожидает подключения реального Life Quality Index.
