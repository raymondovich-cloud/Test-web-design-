# Реализация контракта подготовки данных силовой активности

Дата: 10.10.2026
Время: 16:00
MSK (UTC+03:00)

## Цель

Реализовать изолированную подготовку недельных данных силовой активности без подключения к общему Health Index и без самостоятельного определения физиологической интенсивности упражнений.

## Изменённые файлы

- `source/index/health/health.strength-activity-data.js` — создан Version 1.0.
- `source/index/health/health.strength-activity-data.test.mjs` — создан Version 1.0.
- `docs/health-activity-training-1.0.md` — Version 1.1 → 1.2.
- `docs/changes/10.10.2026/health/activity-training-model/10.10.2026-16.00-strength-data.md` — создан Change Log.

## Реализовано

- Валидация границ недели и календарных дат.
- Проверка принадлежности сессий выбранной неделе.
- Дедупликация qualifying days по календарной дате.
- Отдельный отчёт покрытия групп мышц за неделю.
- Явный признак полноты журнала.
- Отсутствующая классификация и неполные данные не интерпретируются как ноль.
- Выходной статус `prepared_data_only`; итоговый Health Score не рассчитывается.

## Архитектурные ограничения

- Модуль не импортирует UI, Memory, инфраструктуру, Apple Health или сетевые API.
- Модуль не решает самостоятельно, была ли нагрузка физиологически умеренной/интенсивной.
- Перечень основных групп мышц передаётся вызывающей стороной, без навязывания неподтверждённой универсальной таксономии.
- Общий Health Index и legacy-расчёт не изменялись.

## Проверка

Добавлены unit-тесты на дедупликацию дней, покрытие групп мышц, неполный журнал, неизвестную классификацию, сессию вне периода и некорректные границы недели.

Локальный изолированный запуск Node.js `node --test` для 7 сценариев контракта завершился успешно: 7 passed, 0 failed. Выполнялся запуск в отдельном временном каталоге на копии реализованного модуля и тестовых сценариев; это подтверждает логику тестируемых сценариев, но не заменяет CI на самом GitHub-коммите. Для последнего коммита GitHub combined status не вернул подключённых status checks; CI не объявляется пройденным.
