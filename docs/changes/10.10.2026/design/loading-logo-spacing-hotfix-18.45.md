# Срочная корректировка типографики логотипа загрузки

- Дата: 10.10.2026
- Ветка: `feature/pwa-static-cache`
- Изменение: `source/design/patterns/finance.css`, Version 3.19 → 3.20.
- Сохранено системное семейство шрифта `var(--font-family-system)`, чтобы шрифт соответствовал шапке.
- Возвращён прежний компактный межбуквенный интервал `-.065em`, поскольку полный интервал шапки не подходит увеличенному анимированному логотипу на узких экранах.
- Анимация, JavaScript, бизнес-логика и `main` не изменялись.
- Важно: изменение CSS само по себе не объясняет длительную загрузку сайта. Это исправление исключает чрезмерное расширение логотипа; скорость загрузки публикации требует отдельной проверки.
