## Реализовано
- Неизменяемая модель TrainingProgram с валидацией идентичности, даты, длительности, статуса, недельного расписания и назначений упражнений.
- Поддержаны целевые группы мышц, подходы, повторения, отдых и опциональное сопротивление без выдумывания веса для собственного веса.
- Application-сценарии чтения программы и создания/обновления с optimistic concurrency.
- Проверки identity/createdAt, revision, отсутствующей программы, отсутствующего user context и невалидных данных.
- Domain/Application unit-тесты включены в Preview CI.

## Архитектура и безопасность
- Domain не импортирует UI, Supabase, Memory или криптографию.
- Application использует внедряемый repository port; конкретный адаптер и хранение не добавлялись.
- Реальный адаптер обязан применять owner-scope и атомарный compare-and-swap. Не добавлялись клиентское хранение, открытая таблица или фиктивные пользовательские данные.
- Training Overview пока не подключён к программе; read model прогресса и защищённый persistence-адаптер остаются следующим этапом.
