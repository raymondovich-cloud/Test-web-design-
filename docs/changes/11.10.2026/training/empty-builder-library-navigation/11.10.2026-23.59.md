# Переход в библиотеку из пустого конструктора тренировки

Дата: 11.10.2026

## Изменения
- В пустом состоянии конструктора вместо одного поясняющего текста добавлена кнопка «ПЕРЕЙТИ В БИБЛИОТЕКУ УПРАЖНЕНИЙ».
- По нажатию открывается обзор тренировок, раскрывается список библиотеки упражнений и экран плавно прокручивается к нему.
- Библиотека и сохранённые тренировки теперь отображаются в обзоре даже если пользователь ещё не создал ни одного шаблона. Это делает библиотеку доступной при первом входе.

## Архитектура
Изменён существующий компонент Presentation `training.js`. Используется текущий переход к обзору и существующая библиотека упражнений; новые зависимости и изменения БД не нужны. Ветка `feature/pwa-static-cache`; `main` не изменялся.

## Проверка
Необходимо проверить сборку/публикацию и вручную проверить сценарий первого входа без упражнений и без сохранённых шаблонов.
