# Тип упражнения: кардио или силовая тренировка

Дата: 11.10.2026

## Изменения
- В модальном окне добавления упражнения добавлен обязательный выбор типа: «Кардио тренировка» или «Силовая тренировка». По умолчанию выбран силовой тип.
- Тип хранится в `training_exercises.exercise_type`, возвращается библиотекой и сохраняется в составе упражнений шаблона тренировки.
- Для кардио в активной тренировке поле веса и подпись «КГ» не отображаются; ввод повторений остаётся.
- Для силовых упражнений поле веса работает как прежде.
- Кардио-подходы сохраняются с сопротивлением типа bodyweight без запроса веса.

## Архитектура
- Presentation: выбор типа и условное отображение поля веса.
- Application: валидация типа и сохранение его в модели упражнения.
- Infrastructure: чтение/запись `exercise_type` в Supabase.
- Database: миграция добавляет колонку с ограничением значений `cardio|strength`; существующие записи автоматически получают `strength`.
- Новые зависимости не добавлялись. Изменения в `feature/pwa-static-cache`; `main` не изменялся.

## Проверка
Нужно проверить сборку, database tests и публикацию. После применения миграции вручную проверить создание обоих типов упражнений и запуск шаблона с кардио и силовыми упражнениями.
