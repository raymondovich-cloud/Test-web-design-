# Подтверждение удаления используемого упражнения

- Дата: 11.10.2026
- Изменения:
  - `source/presentation/training/training.js` — Version 2.3 → 2.5
  - `source/design/patterns/training.css` — Version 2.1 → 2.2
- Перед удалением проверяются все загруженные сохранённые шаблоны тренировок.
- Если упражнение нигде не используется, удаление продолжает работать без дополнительного шага.
- Если упражнение используется в одной тренировке, появляется диалог с её названием.
- Если упражнение используется в нескольких тренировках, диалог показывает количество и названия всех таких тренировок.
- Удаление происходит только после явного подтверждения. «Отмена», Escape и нажатие вне окна отменяют операцию.
- Атомарное удаление и проверка владельца в базе данных остаются без изменений.
- Исторические завершённые занятия не изменяются.
- Статус: код подготовлен; CI и тестовая публикация требуют проверки.
