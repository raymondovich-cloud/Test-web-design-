## Изменения
- Экран обзора получает явный presentation-флаг наличия сохранённых шаблонов.
- Если шаблон уже существует, но отдельная программа тренировок ещё не создана, первоначальный пустой блок программы не отображается.
- Если шаблонов нет, первоначальный экран создания первой тренировки остаётся доступен.
- После удаления последнего шаблона повторная загрузка обзора возвращает первоначальный экран.

## Архитектурные решения
- Изменение ограничено Presentation: существующие данные шаблонов используются для управления отображением.
- Не меняются бизнес-правила, API хранения, база данных, авторизация и зависимости.
- `main` не изменяется; работа ведётся в `feature/pwa-static-cache`.
