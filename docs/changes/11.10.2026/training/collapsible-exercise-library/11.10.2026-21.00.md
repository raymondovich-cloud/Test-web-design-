# 11.10.2026 — Библиотека упражнений в блоке «Мои тренировки»

## Изменения
- Библиотека упражнений размещена как отдельный вложенный подраздел внутри блока «Мои тренировки».
- Подраздел сворачивается и раскрывается нажатием на заголовок.
- По умолчанию библиотека свёрнута, чтобы не перегружать экран сохранёнными упражнениями.
- Заголовок показывает количество упражнений и состояние раскрытия через стрелку.
- Сохранение тренировок, упражнения и бизнес-логика не менялись.

## Архитектура
- Использованы существующие presentation- и design-слои.
- Новые зависимости и изменения доменной логики не добавлялись.
- main не изменялась; работа выполнена в feature/pwa-static-cache.
