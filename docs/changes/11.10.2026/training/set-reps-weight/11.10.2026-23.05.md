# Повторения и вес в подходах

Дата: 11.10.2026

## Изменения
- В каждой строке подхода добавлено поле повторений и отдельное поле веса в килограммах.
- Вес можно оставить пустым для упражнений с собственным весом.
- При отметке подхода значения повторений и веса передаются через существующую команду application layer `recordSet`.
- Для сохранённых подходов поля блокируются, чтобы отражать уже записанный результат.
- Стили добавлены в существующий Training CSS; новые зависимости не добавлялись.

## Архитектура
UI отвечает за ввод и валидацию формата значений; сохранение результата остаётся в существующем application layer. Изменения внесены в `feature/pwa-static-cache`, основная ветка не менялась.

## Проверка
Требуется проверить результат сборки и прохождение интеграционных тестов после публикации.
