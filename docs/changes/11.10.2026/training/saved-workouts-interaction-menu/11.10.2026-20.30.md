# Меню взаимодействия для сохранённых тренировок

- Дата и время: 11.10.2026, 20:30 MSK (UTC+03:00)
- Пользовательский запрос: убрать кнопки «НАЧАТЬ» и «Удалить шаблон» из сохранённых тренировок; запускать тренировку нажатием на её название; использовать меню взаимодействия по образцу финансовых строк.
- Изменённые файлы:
  - `source/presentation/training/training.js` — Version 1.5 → 1.6.
  - `source/design/patterns/training.css` — Version 1.5 → 1.6.

- Изменение:
  - Удалены отдельные кнопки «НАЧАТЬ» и «Удалить шаблон».
  - Название каждой сохранённой тренировки стало доступной кнопкой запуска.
  - Длительное нажатие на строку тренировки (и контекстное меню на desktop) открывает общий визуальный компонент `row-interaction-menu` с действиями «Начать тренировку» и «Удалить шаблон».
  - Удаление по-прежнему выполняется через существующий Application callback; бизнес-логика и persistence-контракты не менялись.
- Причина: упростить строку и перенести дополнительные действия в единое меню взаимодействия, визуально согласованное с Finance.
- Архитектурные решения: UI-поведение добавлено в Presentation; повторно используется существующий CSS-компонент меню из Design System, без новых зависимостей.
- Итоговый статус: изменения записаны в рабочую ветку; CI и тестовая публикация требуют проверки.
