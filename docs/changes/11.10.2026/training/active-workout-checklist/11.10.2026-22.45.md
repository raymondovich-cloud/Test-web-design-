# Активная тренировка: интерфейс подходов

Дата: 11.10.2026

## Что изменено
- Экран активной тренировки адаптирован под механику чек-листа: карточки упражнений, нумерованные подходы, поле повторений, отметка выполненного подхода.
- Добавлен таймер продолжительности тренировки.
- Добавлена возможность свернуть карточку упражнения и добавить подход.
- Выполнение подхода по-прежнему сохраняется через существующий `trainingSessionApplication.recordSet`; завершение — через `completeWorkout`.
- Стили добавлены в существующую дизайн-систему Training CSS. Новые зависимости не добавлялись.

## Архитектурная граница
UI-компонент отвечает за отображение и взаимодействие; сохранение и бизнес-правила остаются в application layer. Изменения внесены в тестовую ветку `feature/pwa-static-cache`. `main` не изменялся.

## Проверки
Автоматическая сборка и публикация тестовой версии должны быть подтверждены по результатам GitHub Actions после коммитов.
