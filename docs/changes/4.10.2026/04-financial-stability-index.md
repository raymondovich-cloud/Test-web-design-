# Индекс финансовой стабильности

Дата: 04.10.2026

В Finance добавлен шестой блок — «Индекс финансовой стабильности».

## Архитектура

- расчёт находится в `source/index/finance/finance.index.js`;
- `source/domain/finance` не изменён и не хранит данные индекса;
- application layer собирает факты Finance и передаёт их в Index layer;
- presentation layer только отображает результат;
- отдельной Domain-папки для индекса не создавалось.

## Версия расчёта

Версия 1.0 нормализует результат в диапазоне 0–100 и использует три компонента:

- ликвидность — 40%;
- финансовая нагрузка — 30%;
- финансовая подушка — 30%.

Расчёт изолирован в Index layer и может быть изменён отдельно от Domain.
