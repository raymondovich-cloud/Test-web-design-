Дата: 04.10.2026

## Изменено

- Зафиксирована каноническая формула ИФС-1000 в `source/index/finance/finance.index.js`.
- Индекс переведён на шкалу 0–1000.
- Добавлены пять компонентов P₁–P₅ по 200 баллов.
- P₁ получает общую сумму долгов из блока 03.
- P₃ получает регулярные платежи из блока 03.
- Блок 03 «Финансовая нагрузка» расширен:
  - название обязательства;
  - общая сумма долга;
  - регулярный платёж.
- Application слой получил отдельную операцию добавления финансовой нагрузки.

- Блок 06 теперь отображает все пять компонентов ИФС-1000 по шкале 200 баллов.
- Зафиксирован эталонный демонстрационный результат 753/1000.

## Архитектура

Формула находится в `source/index/finance`, а не в `source/domain/finance`.

Блок 03 остаётся источником долговых обязательств. Индекс использует из него две разные величины:

- сумма задолженности → P₁;
- регулярные платежи → P₃.

## Следующий шаг

Отдельно определить и реализовать корректный источник всех активов для P₁: недвижимость, автомобиль, наличные и деньги на счетах. Текущий Liquid Funds не должен автоматически считаться полным имущественным балансом.
