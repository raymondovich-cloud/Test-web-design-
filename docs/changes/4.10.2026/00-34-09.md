Дата: 05.10.2026

## Пользовательский запрос

Проверить текущую архитектуру LifeGame и реализовать согласованный Info Tooltip для блоков Finance согласно docs/agent.md.

## Изменённые файлы

- source/presentation/shared/info.tooltip.js — создан, Version 1.0; после уточнения Version 1.1.
- source/design/components/info.tooltip.css — создан, Version 1.0; после уточнения Version 1.1.
- source/design/design.css — Version 1.0 → 1.1.
- source/design/components/accordion.css — Version 1.7 → 1.8.
- source/presentation/finance/finance.js — Version 1.17 → 1.18.
- docs/changes/4.10.2026/00-34-09.md — текущая запись изменения.

## Что изменено

- Добавлен переиспользуемый presentation-компонент Info Tooltip без размещения JavaScript внутри Design System.
- Добавлен CSS-компонент Info Tooltip в Design System.
- Desktop получает tooltip по наведению, touch-устройства — по нажатию.
- Одновременно открыт только один tooltip.
- Повторное нажатие закрывает tooltip.
- Нажатие вне tooltip закрывает его.
- Escape закрывает открытый tooltip и возвращает фокус на кнопку.
- Добавлена ARIA-связь между trigger и tooltip.
- Для мобильных экранов предусмотрено фиксированное позиционирование подсказки.
- В каждый из шести Finance-блоков добавлен единый информационный tooltip.
- Кнопка раскрытия блока и информационная кнопка разделены: tooltip не вложен в accordion trigger.
- Domain, Application, Memory и Infrastructure не изменялись.

## Архитектурные решения

- Design System содержит только CSS и визуальные правила.
- Поведение tooltip находится в source/presentation/shared.
- Domain не получает зависимость от UI.
- Finance использует переиспользуемый presentation-компонент.
- Новый компонент не добавляет бизнес-логику и не хранит пользовательские данные.
- Для нового CSS-компонента использованы существующие Design Tokens.

## Итоговый статус

Реализация согласованного Info Tooltip завершена.
