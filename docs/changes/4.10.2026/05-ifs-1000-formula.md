# ИФС-1000 — индекс финансового состояния

Дата фиксации: 04.10.2026

## Назначение

Индекс финансового состояния (ИФС-1000) — единый показатель личных финансов в диапазоне от 0 до 1000 баллов.

ИФС = P₁ + P₂ + P₃ + P₄ + P₅

Каждый компонент даёт максимум 200 баллов.

## Компоненты

### P₁ — Ликвидные средства / имущественный баланс

Стоимость недвижимости, автомобиля, наличных и денег на счетах минус общая сумма долгов и кредитов.

Формула:

Активы − Долги > 0 → 200 баллов  
Активы − Долги ≤ 0 → 0 баллов

### P₂ — Фактически заработано / профицит бюджета

Показывает, насколько чистый заработок превышает среднемесячные расходы.

Формула:

((Доход / Расходы) − 1) × 200

Результат ограничивается диапазоном 0–200.

### P₃ — Финансовая нагрузка

Оценивает долю дохода, которую забирают регулярные платежи по кредитам и долгам.

Формула:

(1 − Платежи / Доход) × 200

Результат ограничивается диапазоном 0–200.

### P₄ — Контроль трат

Оценивает среднемесячные расходы относительно фактически заработанного дохода. Кредитные платежи в этот показатель не входят.

Формула:

(1 − Расходы / Доход) × 200 × 2

Результат ограничивается диапазоном 0–200.

### P₅ — Финансовая подушка

Показывает, сколько месяцев пользователь сможет прожить при полной потере дохода.

Формула:

((Подушка / Расходы) / 6) × 200

Максимум — 200 баллов.

## Демонстрационный расчёт

P₁ = 200  
P₂ = 133  
P₃ = 160  
P₄ = 160  
P₅ = 100

ИФС = 200 + 133 + 160 + 160 + 100 = 753 / 1000

## Интерпретация

0–400 — критическое состояние.

410–700 — неустойчивое состояние.

710–1000 — финансовое благополучие.

## Архитектурное правило

Формула ИФС-1000 находится в:

source/index/finance/finance.index.js

Индекс не является частью:

source/domain/finance

Domain не содержит формулу индекса и не хранит пользовательские результаты индекса.

Индекс получает необходимые финансовые показатели через внешний слой и выполняет только расчёт.

## Важное состояние реализации

Формула ИФС-1000 зафиксирована как каноническая методика версии 2.0.

Для P₁ требуется отдельное значение общей суммы активов и отдельное значение общей суммы долгов и кредитов. Текущий Finance Domain ещё не содержит отдельного поля для основной суммы долгов, поэтому расширение источника этих данных выполняется отдельно и не должно подменяться финансовыми платежами.

Демонстрационный расчёт 753 балла является эталонным тестовым примером методики.


## Актуализация семантики P₁ — 05.10.2026

Блок пользовательского ввода P₁ теперь называется **«Активы»**. Он включает как ликвидные, так и неликвидные активы: например, деньги на счёте, квартиру или автомобиль.

Для расчёта ликвидности FSI используется только часть активов, явно отмеченная как ликвидная. Общая стоимость активов не должна автоматически считаться денежной ликвидностью.

Это изменение уточняет границу между **имущественным балансом** и **ликвидностью**. Оно не утверждает новую методику оценки рыночной стоимости недвижимости, автомобилей или других неликвидных активов; такие правила должны быть отдельно валидированы финансовым экспертом.
