# Profile navigation

Дата: 04.10.2026

## Изменение

Исправлено отображение вкладки Profile после успешной авторизации.

CSS больше не использует отдельное глобальное правило, которое принудительно скрывает Profile вне зависимости от состояния приложения. Видимость Profile теперь определяется только состоянием доступа приложения: до авторизации вкладка скрыта, после авторизации отображается как четвёртая вкладка.

## Архитектура

Регистрация и авторизация не изменялись.

Существующий application/presentation flow сохранён:

- authentication определяет состояние сессии;
- web composition передаёт состояние в application shell;
- navigation отвечает за навигацию;
- Design System отвечает только за визуальное состояние вкладки.
