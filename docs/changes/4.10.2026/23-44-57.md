# Изменение интерфейса «Ликвидные средства»

**Дата и время создания:** 04.10.2026 23:44:57  
**MSK (UTC+03:00)**

## Пользовательский запрос

Переработать интерфейс блока «Ликвидные средства» с учётом согласованной модели имущественных активов и требований `docs/agent.md`.

## Изменённые файлы

- `source/presentation/finance/finance.js` — Version 1.13 → 1.14
- `source/presentation/finance/liquid.funds.statistics.js` — создана Version 1.0
- `source/application/finance/finance.js` — Version 1.3 → 1.4
- `source/design/patterns/statistics.css` — Version 1.9 → 1.10

## Что изменено

1. Встроенная статистика удалена из раскрываемого блока «Ликвидные средства».
2. Кнопка «Статистика» теперь открывает отдельный экран статистики внутри presentation-слоя.
3. На основном экране отображаются:
   - дата текущего состояния;
   - текущее состояние имущественных активов;
   - список внесённых активов;
   - краткое изменение состояния за последний месяц;
   - кнопка перехода к полной статистике.
4. Для поля добавления в блоке «Ликвидные средства» используется обозначение «Актив» вместо «Название».
5. Экран статистики содержит периоды «Неделя / Месяц / Год», текущее состояние, изменение за период, историческую точку сравнения и текущий список активов.
6. Процент изменения рассчитывается как изменение пользовательского состояния между текущим снимком и историческим снимком из Memory.
7. При отсутствии достаточной исторической базы отображается «Недостаточно данных для расчёта», а не искусственное значение 0%.
8. Для периода используются скользящие интервалы: 7 дней, 1 месяц и 1 год.
9. Расчёты статистики находятся в application-слое; presentation отвечает только за отображение и взаимодействие.
10. `IFS 2.1`, `source/index/finance/finance.index.js`, Profile и глобальная навигация не изменялись.

## Архитектурные решения

- Пользовательские данные не переносятся в Domain.
- Исторические снимки читаются через существующий Memory bridge.
- Новый экран вынесен в отдельный файл согласно принципу «один файл = одна ответственность».
- Техническое имя `liquid-funds` пока сохранено. Переименование будет рассмотрено после формирования всех пяти финансовых блоков.
- IFS 2.1 намеренно не пересматривается до завершения финансовой модели.
